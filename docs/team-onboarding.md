# GlobalTrend 담당자 안내

작업실에서 자료를 읽고, Codex에게 고칠 내용을 말한 뒤, 바뀐 내용을 확인할 수 있습니다. 공개하기 전에는 반드시 내용을 먼저 읽어 보세요.

## 먼저 할 일

1. 동향 담당자는 [동향 작업실](/team?role=trends), 법제 담당자는 [법제 작업실](/team?role=legal)을 엽니다.
2. 동향 담당자는 로그인 화면이 나오면 평소 쓰는 작업실 계정으로 로그인합니다.
3. 화면에서 **Codex에 수정 요청하는 방법 · 예시 프롬프트**를 엽니다.
4. **Codex 연결 프롬프트 복사**를 누르고, 본인 Codex 대화창에 붙여 넣습니다.
5. 프롬프트 맨 끝에 고치고 싶은 점을 편하게 적어 보냅니다. 여러 가지를 한 번에 말해도 됩니다.
6. Codex가 다 고쳤다고 하면 작업실로 돌아와 **지금 새로 확인**을 누르고, 바뀐 내용을 다시 읽습니다.

## 동향 담당자

1. 원고 제목을 눌러 제목, 요약, 본문과 원문 링크를 확인합니다. 검색칸에 나라·기관·제목을 입력하면 찾기 쉽습니다.
2. 고칠 점을 Codex에 한꺼번에 말합니다. Codex가 저장을 마치면 작업실에서 다시 확인합니다.
3. 자동수집 자료는 한국어 원고 초안까지 만들어져 저장되면 이 원고 목록에 나타납니다. 원문만 모였거나 초안 작성이 멈춘 자료는 **수집 상태**에서 확인합니다.
4. 공개할 글 옆 네모를 체크합니다. 여러 개를 고르거나 **현재 검색 결과 중 공개 가능한 자료 선택**을 눌러 한꺼번에 고를 수 있습니다.
5. **선택한 원고 공개** 옆 숫자가 맞는지 보고 누릅니다. 한 번 더 확인하는 창에서 공개할 개수를 확인합니다.
6. 끝나면 성공·실패한 글 수가 나옵니다. 실패한 글은 화면에 나온 이유를 읽고 다시 처리합니다.

이미 공개된 글은 이 선택 목록에서 다시 공개하지 않습니다. 공개된 글을 고쳐야 한다면 최신 원고와 수정본을 대조한 뒤 프로젝트 리드에게 알려 주세요.

## 법제 담당자

1. **17개 기준 비교표**를 열어 각 나라의 비교 내용을 읽습니다. 칸을 누르면 자세한 설명과 근거를 볼 수 있습니다.
2. **법률별 전체 번역**을 열고 확인할 법률을 고릅니다. 번역을 처음부터 끝까지 읽고 빠진 조문이나 어색한 말을 메모합니다.
3. 메모한 내용을 Codex에게 한 번에 말합니다. Codex가 저장을 마치면 **지금 새로 확인**을 누르고 비교표와 번역문을 다시 읽습니다.
4. 비교표 화면 아래의 **17개 기준 비교표 수정 내용 공개**에서 바뀐 법률을 찾습니다. 그 법률의 비교표와 전체 번역이 함께 공개됩니다.
5. 처음 공개하는 법률이면 **이 법률 공개**, 이미 공개한 법률을 새 내용으로 바꾸려면 **이 법률의 수정 내용 공개**를 누릅니다. 확인 창에서 법률 이름을 확인하고 진행합니다.
6. 이 버튼은 선택한 법률의 비교표와 전체 번역을 함께 바꿉니다.
7. 공개를 취소해야 하면 **현재 공개 취소**를 누릅니다. 자료 자체는 작업실에 남습니다.

## 화면에 자료가 안 보이거나 바뀌지 않을 때

- 먼저 **지금 새로 확인**을 누릅니다.
- ‘일부 자료’ 또는 오류 문구가 나오면 전체 자료가 다 보이는 상태가 아닙니다. 그 문장을 복사해 프로젝트 리드에게 보내세요.
- Codex가 바꿨다고 했는데 화면이 그대로면 Codex에게 “저장까지 했는지 확인하고, 저장한 위치와 결과를 알려줘”라고 물어보세요.
- 공개 버튼이 보이지 않으면 작업실 관리자에게 “공개할 수 있는 담당자로 등록해 주세요”라고 요청하세요.
- 동향 로그인 암호나 화면에 나온 연결키를 다른 사람에게 보내지 마세요.

공개 자료는 [공개 페이지](/public)에서 확인할 수 있습니다. 더 자세한 기술 설명은 [작업실 기술 안내](./live-team-workspace.md)에 있습니다.
