# GlobalTrend 담당자 작업 안내

이 안내의 기준일은 2026-10-26입니다. 예전 PR 제출·항목별 피드백 안내와 다르면 아래 최신 작업 흐름을 따르세요.

## 하는 일은 간단합니다

1. 본인 역할의 작업실을 엽니다. 동향은 [동향 작업실](/team?role=trends), 법제는 [법제 작업실](/team?role=legal)입니다.
2. 동향 담당자는 사이트 팀 계정으로 로그인해 원고를 읽습니다. Supabase 관리자 계정이 따로 필요한 것은 아닙니다.
3. 화면에서 **Codex에 수정 요청하는 방법 · 예시 프롬프트**를 열고 **Codex 연결 프롬프트 복사**를 누릅니다.
4. 복사한 문장을 본인의 Codex에 붙여 넣고, 맨 끝에 고칠 점을 자연어로 적습니다.
5. Codex가 저장한 뒤 같은 화면에서 내용을 확인합니다. 화면은 2분마다 새로 확인합니다.

항목마다 피드백을 하나씩 등록할 필요는 없습니다. 화면을 훑어본 뒤 Codex에게 여러 항목의 수정을 한 번에 요청하셔도 됩니다.

## 담당자별 화면

- 동향 작업실은 DB에 있는 원고 전체와 GitHub 조사 자료를 한 곳에서 검색·열람합니다. API의 전체 원고 수와 DB 연결이 완전한지 화면에서 확인합니다.
- 법제 작업실에는 **17개 기준 비교표**와 **법률별 전체 번역**만 있습니다. 제출 자료 목록은 사용하지 않습니다.

## Codex 연결과 저장 위치

작업실 프롬프트는 GitHub 저장소, 읽을 자료 주소, 자료별 수정 방법, 검사와 재확인 절차를 알려줍니다.

동향 원고를 Codex가 읽을 수 있도록 팀원이 복사할 때 24시간 연결키를 발급합니다. 키는 읽기와 비공개 작업실 수정본 저장만 허용합니다. 운영 원고 변경, 발행, 삭제, 회원 관리는 못 합니다. 새 연결키를 발급하면 같은 계정의 이전 키는 해제됩니다. 필요하면 화면에서 키를 바로 해제할 수 있습니다. Codex에게 계정 비밀번호나 Supabase 관리자 키를 보내지 마세요. 프롬프트와 연결키를 공개 GitHub·PR·파일·로그에 저장하지 않습니다.

동향 DB 원고 수정본은 DB의 비공개 작업실 테이블에 저장됩니다. 최신 원고나 다른 담당자의 수정본이 먼저 바뀌었다면 덮어쓰지 않고 충돌을 표시합니다. 초안은 자동 발행되지 않습니다.

법제 전문·비교표와 GitHub에만 있는 동향 자료는 각 담당 브랜치에 저장합니다.

- 동향: `feat/trend-source-contracts`
- 법제: `feat/legal-corpus-foundation`

Codex가 브랜치에 push해야 코드 자료 변경이 화면에 반영됩니다. 새 브랜치를 만들 필요는 없습니다. 매번 PR 병합하거나 사이트를 재배포하지 않아도 됩니다. 이전 고정 Preview 주소는 그 코드가 자동으로 바뀌지 않으므로 새 작업실 기능이 들어간 사이트를 이용하세요.

## 권한이 없다는 오류가 나면

- 로그인 화면: 사이트 팀 계정으로 로그인합니다. 계정 비밀번호를 Codex에 전달하지 않습니다.
- 403 오류: 연결키가 만료·해제됐거나 로그인 계정의 팀 등록을 확인해야 합니다. 프롬프트를 새로 복사하거나 사이트 관리자에게 팀 계정 여부를 확인해 달라고 알려 주세요.
- 409 오류: 원고나 수정본이 먼저 바뀌었습니다. Codex가 최신 자료를 다시 읽고 겹치는 수정을 대조해야 합니다.
- 전체 동향 원고가 안 보임: 화면에 ‘일부 자료’ 또는 연결 오류가 표시됩니다. 전체를 확인한 것처럼 보고하지 말고 그 오류 문구를 전달합니다.
- 화면에 수정이 안 보임: Codex 대화만으로 끝나지 않았는지, GitHub 자료라면 push가 됐는지, 동향 자료라면 작업실에 다시 저장하고 읽었는지 확인합니다.

‘관리자 권한이 필요하다’고 임의로 결론 내리지 않습니다. 오류 상태와 문구를 그대로 확인해 담당 경로를 고칩니다.

## 공개와 발행은 별도입니다

작업실은 자료를 읽고 수정하는 곳입니다. 작업실에 저장했다고 공개 페이지에 발행된 것이 아닙니다. 대외 공개는 기존 운영 발행 흐름에서 담당자가 따로 결정합니다. 공개 서비스는 [공개 페이지](/public)에서 확인할 수 있습니다.

자세한 데이터 경로·연결키·충돌 처리 설명은 [작업실 기술 안내](./live-team-workspace.md)를 보세요.
