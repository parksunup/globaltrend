# 법제 비교·번역의 용어 편집 기준

2026-11-02 · 법제 담당 사용자 요청: 같은 용어를 통일하고, 원문 뜻을 유지하면서 쉽게 설명하며, 가능한 범위에서 한국 개인정보 보호법 용어를 사용합니다.

공통 [용어집](glossary.md)을 기본으로 적용하되, 법제 비교표·법률별 번역에는 아래의 구체적인 편집 기준을 우선합니다. 다른 담당자의 원고·원 조사 기록·공식 원문은 이번 편집 대상에 포함하지 않습니다.

| 대상·원어 | 법제 자료의 표기 | 유지할 구별 |
|---|---|---|
| EU·UK controller | 개인정보처리자(controller), 이후 개인정보처리자 | 목적·수단 결정자라는 각 법률의 정의를 유지합니다. 한국법·중국법과 범위가 같다고 단정하지 않습니다. |
| EU·UK processor | 수탁자(processor), 이후 수탁자 | 개인정보처리자를 대신해 처리하는 역할입니다. 법률별 계약·재위탁·직접 의무를 보존합니다. |
| 싱가포르 data intermediary | 수탁자(data intermediary), 이후 수탁자 | 다른 조직을 대신해 그 조직의 목적에 따라 처리하는 PDPA상 역할입니다. 위탁 조직의 책임과 구별합니다. |
| CCPA contractor | 계약자(contractor), 이후 계약자 | 계약수행자/계약자 혼용을 정리합니다. 서비스 제공자와 합치지 않습니다. |
| CCPA service provider | 서비스 제공자 | 한국법상 수탁자와 같은 범위로 단정하지 않습니다. |
| PIPL·CCPA sensitive personal information | 민감정보 | 해당 법률의 정의·정보 유형·처리 조건을 보존합니다. |
| EU·UK special categories of personal data | 특별한 유형의 개인정보 | 한국법 민감정보와 유사한 보호 대상이지만 범위·조건은 다를 수 있습니다. |
| 일본 要配慮個人情報 | 요배려 개인정보(배려가 필요한 정보), 이후 요배려 개인정보 | 개인정보·개인데이터·보유 개인데이터 및 조례상 별도 개념을 구별합니다. |
| data protection officer | 개인정보 보호책임자 | 법률별 지정·독립성·업무 요건을 보존합니다. |
| administrative fine | 행정상 금전제재 | 과징금·과태료·형사벌금·민사상 제재금을 같은 제도로 합치지 않습니다. |
| data portability | 개인정보 이동권(전송요구권) | 행사 요건·대상 정보·직접 전송 범위가 법률별로 다릅니다. 중복 표기를 없앱니다. |
| pseudonymisation / anonymisation | 가명처리 / 익명처리 | 가명정보와 익명정보의 정의·재식별 가능성·법 적용 여부를 구별합니다. 일본의 별도 가공정보 용어를 합치지 않습니다. |

긴 비교 설명은 핵심 요약과 조항별 상세 조건으로 나눌 수 있습니다. 조건·예외·숫자·기한·조항 근거를 삭제하지 않습니다. 의무와 노력의무, 신고와 개인 통지, 이상·초과, 원칙과 예외, 공포·시행·적용일도 구별합니다.

용어·문장을 다듬었다는 사실은 새 판본의 현행성 검증이나 사람 의미·법률 검수 완료를 뜻하지 않습니다. [이번 편집의 범위·근거·남은 쟁점](../../data/legal/terminology-edit-review-20261102.md)을 함께 확인합니다.
