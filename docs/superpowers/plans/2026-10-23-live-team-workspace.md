# 담당자 최신 작업 화면

## 요구사항
- 기존 담당 브랜치에 push한 자료를 PR 병합/자료별 재배포 없이 고정 검수 주소에서 표시한다.
- 법제/동향 제출 자료의 열람과 대외 발행을 분리한다. 공개 보류/미검수도 제출된 본문을 표시한다.
- Supabase 권한/로그인 없이 공개 저장소에 이미 제출된 자료와 기존 익명 피드백을 이용한다. 비공개 DB 자료는 가져오지 않는다.
- 작성 중인 ChatGPT 대화나 push하지 않은 파일은 볼 수 없음을 명확히 안내한다.

## 구현
1. 테스트: 브랜치 변경 후 새 결과, 동일 commit의 일관성, 미발행 번역 표시, GitHub 실패/경로 제한.
2. 고정된 두 브랜치만 읽는 GitHub snapshot loader. branch 목록을 공유 캐시하고 immutable SHA로 tree/raw 자료를 읽는다. 공개 API 제한을 고려해 2분 간격, 실패 시 마지막 성공본과 오류 표시. 서버 전용 선택적 읽기 토큰 지원.
3. /team 담당 선택 화면과 자동 새로고침. 번역 전문/비교표/동향 표본 및 보조 문서를 제공하고 피드백에 실제 자료 SHA를 연결한다. 기존 법제 검수 경로도 같은 최신 데이터 사용.
4. 테스트 전체/타입 검사/빌드 및 최신 공개 브랜치 smoke 검증. 최초 기능 배포는 필요하지만 이후 자료 업데이트에는 배포가 필요하지 않다.

## 진행 기록
- 기존 운영 발행본이 제출 자료를 덮어쓰는 경로를 발견. 최신 검수 화면은 운영 발행본을 혼합하지 않는다.
- 기존 사용자 파일 보존을 위해 격리 worktree, 최신 main e63de6a 기준 codex/live-team-workspace 사용.
- 완료: GitHub 최신 SHA 읽기, 허용된 두 브랜치 격리, 공유 fetch 캐시, 자동 갱신 UI, 미발행 번역 열람, 공개 화면/발행 정책 유지.
- 추가 수정: 익명 검수 API/번역 경로가 Supabase 세션 middleware를 초기화하지 않도록 분리. 자동 갱신 중 작성한 피드백은 작성 시작 SHA에 연결.
- 검증: Node 테스트 144/144, 타입 검사, 데이터 검사, 보고서 21건 형식 검사, 프로덕션 빌드 통과. 기존 CSS autoprefixer 경고는 남아 있음.
- 브라우저 검증: 실제 동향 브랜치 c42db8b(30항목), 법제 브랜치 5b7eff5(13항목/119셀/번역6개), 익명 열람·번역·390px 모바일·두 자료 버전 자동 갱신·장애 후 마지막 결과 보존 통과.
- 자체 검토: 공개 app/public 및 첫 화면은 변경하지 않음. DB 읽기/쓰기·발행 권한 변경 없음. JSON API는 현재 공개 저장소의 제출물만 반환. 실제 피드백 DB에는 시험 의견을 쓰지 않음.
- 한계: 최초 기능 배포 1회는 필요. GitHub 장애/요청 한도는 명시적 오류이며 무조건 최신을 보장한다고 표시하지 않음. 큰 자료는 분할 읽기를 추가해야 함.
