# 검토용 웹앱 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Vercel Preview에서 팀원이 수집 출처·법제·비교 기준을 확인할 수 있는 정적 검토 화면을 제공한다.

**Architecture:** Next.js App Router 단일 페이지에 샘플 데이터를 주입하고, 화면 상태는 클라이언트 컴포넌트에서 관리한다. Supabase 연결과 mutation은 후속 PR에서 추가한다.

**Tech Stack:** Next.js, TypeScript, Tailwind CSS, Vercel.

**Spec:** docs/superpowers/specs/2026-09-27-review-ui-design.md

## Global Constraints

- 이번 PR은 정적 샘플 데이터만 사용한다.
- 상태 변경·로그인·Supabase 쓰기를 구현하지 않는다.
- Preview에서 샘플 데이터임을 표시한다.
- 데스크톱 3열, 좁은 화면 세로 배치를 지원한다.

## Review Focus

- 세 가지 데이터 유형 전환 시 목록과 상세 패널이 함께 바뀌는가.
- 검색어와 상태 필터가 동시에 적용되는가.
- 선택 항목이 필터 결과에서 사라질 때 안전하게 첫 항목으로 이동하는가.
- 공식 URL이 외부 링크로 열리는가.
- 좁은 화면에서 패널이 잘리지 않는가.
