## 자료와 공개

- 법제 자료의 기준은 #15 063a927, 동향 자료의 기준은 #16 c42db8b이다. #30의 과거 복사본으로 덮어쓰지 않는다.
- 법률 전문을 먼저 읽고 동일 법률을 17개 기준으로 비교한다. 119개 셀/6개 외국법 번역 초안/한국 공식 원문 색인의 구별과 검수 상태를 보존한다.
- 검토 Preview에서는 제출 자료를 명확한 초안 표시와 함께 읽는다. 운영에서는 Supabase의 승인·발행 자료만 읽는다. 특정 브랜치 이름에 의존하는 표시 조건은 제거한다.
- 저장소의 산출물은 이력/검수 입력, Supabase는 운영 판본·검수·발행 상태의 기준이다. 중복 수입과 변경된 판본의 조용한 덮어쓰기를 금지한다.
- 수집→정확한 원문 판본→Codex 초안→검수→승인→발행의 기존 동향 흐름을 유지한다. 별도 유료 AI API를 추가하지 않는다.
- 수집 예약과 원격 실행 스위치는 비활성 유지한다. 운영 자료를 시험 목적으로 발행하지 않는다.
