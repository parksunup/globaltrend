# 1·2차 해외 동향 출처 확대

사용자 승인: 2026-10-28 KST 대화에서 1·2차 전체를 동시에 검토하고 Edge 우선으로 구축하도록 명시적으로 지시했다. 별도 설계 승인 질문 없이 이 범위에서 구현한다.

## 목표와 범위
- EDPS, EC, CalPrivacy(CPPA), OAIC, 캐나다 OPC, 홍콩 PCPD, 유럽의회, EU 이사회, EUR-Lex, CAC, TC260의 11개 출처를 전부 검토한다.
- 1·2·3차는 실행일(한국시간)과 직전 이틀, 합계 3일 범위로 매일 확인한다. 미실행 날짜는 별도 따라잡기 범위로 보존한다. 주간호는 직전 월~일 발표 자료 중 주요 약 8건을 기존 월요일 예약이 선정·초안 저장한다.
- 의회·법원 수집 대상은 공식 보도자료이다. 법률안·법률·판결 전문 수집으로 확대하지 않는다. EUR-Lex는 기존 후보 범위에 포함해 뉴스 경로를 평가하되, 법령 전문을 대체 수집하지 않는다.
- 후속 협의체·표준기구는 주 1회 수집 대상으로 문서에만 반영하고 이번에는 등록하지 않는다.
- 보존 결정한 모든 자료는 한국어 제목·요약·본문 검증 및 /work 저장까지 완료해야 한다. 신규 생성 API, 유료 서비스, 자동 승인·공개 발행은 추가하지 않는다.

## 접근 방식
1. Edge 우선: 기존 Deno 어댑터·DB 큐·일일 3일 창과 초안 RPC를 재사용한다. 출처별 공식 목록·본문·게시일·robots·허용 호스트를 검증한다.
2. 클라우드 Python 예외: Edge 실제 접근 실패가 있고 Python 경로에서 원문 확보가 검증될 때만 예외로 사용한다. ChatGPT 예약은 모든 보존 자료의 한국어 작성 소비자이다.
3. 미검증 출처는 명시적으로 보류한다. HTTP 200 빈 페이지나 검색 결과만으로 정상 수집으로 등록하지 않는다. 사이트 정책·접근 차단을 우회하지 않는다.

## 구현과 안전 조건
- 확장 어댑터는 기존 9개와 분리한 모듈로 구현하고 discover/extract/runtime에 연결한다.
- 목록별 기사 경로·게시일 위치·본문 위치를 실관찰 fixture로 테스트한다. 수정일·본문 날짜를 게시일로 추정하지 않는다. 빈 목록·템플릿 변경은 실패로 남긴다.
- 동일 URL·본문 hash·판본의 기존 멱등 저장을 유지한다. 실패 URL, queue lease, 기존 cursor를 초기화하지 않는다.
- 새 출처는 검증 상태를 기록하며 검증되지 않은 경로를 정기 큐에 넣지 않는다. 기존 legacy HTML 수집기에 중복 등록하지 않는다.
- 실행·실패·수집·초안 저장을 분리해 보고한다. 아직 보지 못한 실제 예약 실행을 성공으로 표현하지 않는다.
