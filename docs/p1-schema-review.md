## 이 PR의 목적

P1 세로 슬라이스에서 다음 흐름을 저장할 수 있는 최소 데이터 기반을 만듭니다.

`공식 출처 등록 → 자료 수집 → Codex 초안 작업 → 사람 검수 → 발행 → 법조문 연결`

화면, 크롤러, Codex Automation 자체는 이 PR에 포함하지 않습니다.

## 저장하는 데이터

| 영역 | 저장 내용 | 예시 |

| 팀 | 사용자 프로필, 팀 역할 | 관리자·편집자·검수자 |

| 검수 | 승인·수정·연결 확인 이력 | 누가 언제 승인했는지 |

## 공개와 팀 전용

- 방문자는 발행된 동향, 공개된 법령 번역, 공개된 비교표만 읽습니다.
- 팀원은 수집 원문, 초안, 미검수 번역, 비교표 편집 내용을 관리합니다.
- DB의 모든 public 테이블에 RLS를 켰습니다.
- 팀 역할은 `team_memberships`에서 관리하며, 사용자 프로필의 임의 값을 권한으로 사용하지 않습니다.
- Codex 작업은 초안 작성 권한만 갖고 발행 승인 권한은 갖지 않습니다.

## 실제 P1 예시

1. EDPB 출처를 등록합니다.
2. EDPB 자료가 `source_items`에 들어갑니다.
3. Codex 초안 작업이 `draft_jobs`에 생성됩니다.
4. Codex가 한국어 초안을 `reports`에 저장합니다.
5. 팀원이 검수하고 `published` 상태로 승인합니다.
6. 필요하면 해당 보고서와 법조문을 `report_provision_links`로 연결합니다.
