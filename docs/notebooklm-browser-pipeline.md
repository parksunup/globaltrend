# 국제요정 NotebookLM 제작 연결

> 2026-10-27: 기본 제작 경로를 [클라우드 제작](notebooklm-cloud-pipeline.md)으로 변경했습니다. 아래 내용은 기존 Chrome 제작 선택지의 사용법·검증 기록입니다. 클라우드 방식에서는 이 확장 도구를 설치할 필요가 없습니다.

## 이용 순서

1. `/team/podcast`를 열고 사이트 관리자 계정으로 로그인합니다.
2. 본인 Chrome에서 NotebookLM에 Google 로그인을 한 번 합니다. 로그인 상태가 유지되는 동안 재사용하며 비밀번호·Google 쿠키를 국제요정에 보내지 않습니다.
3. 제작 화면의 **연결 도구 받기**로 ZIP을 받고 압축을 풉니다. `chrome://extensions`에서 개발자 모드를 켜고 압축 해제한 폴더를 로드합니다. 제작 화면에서 확장 아이콘을 열고 **이 작업실 연결**을 한 번 누릅니다.
4. 기간과 메인 주제 1건, 선택적인 짧은 소식 1건을 고릅니다. 메인 주제의 관련 자료는 이전 시기 자료도 최대 8건 연결할 수 있습니다.
5. **팟캐스트 만들기**를 누르면 새 전용 노트북에 공개 원고와 공식 출처 링크, 한국어 심층 분석 지시문을 넣고 생성을 시작합니다. 오디오를 회수해 같은 회차에 저장합니다.
6. 운영 사이트에서 **완성되면 이 회차를 바로 공개**를 선택한 경우 저장 직후 게시합니다. 선택하지 않으면 완성본을 듣고 **공개하기**를 누릅니다. Preview·로컬에서는 실제 공개를 차단합니다.

## 실행 조건과 복구

- 이 화면과 NotebookLM 탭이 열린 Chrome이 켜져 있어야 합니다. Google에서 생성 중인 결과는 NotebookLM에 남습니다. 껐다 켰으면 작업실의 제작 현황에서 **이어서 진행**을 누릅니다.
- 확장 도구는 사용자가 연결한 정확한 작업실 주소에서만 명령을 받습니다. 다른 사이트와 관련 없는 NotebookLM 탭은 조작하지 않습니다.
- Google 로그인·사용량 한도·새 확인 창·예상하지 못한 화면에서는 중단 이유를 표시합니다. 유료 서비스로 전환하지 않습니다.
- 주간호 번호와 제작 자료를 고정하며, 재시도 때 이미 만든 노트북·음성을 이어 씁니다. 생성 버튼을 다시 누르는 대신 기존 결과를 기다립니다.
- 생성 중에 원래 동향 내용이 달라지거나 동향 공개가 취소되면 게시를 중단합니다. 이전 음성을 새 자료에 맞는 것처럼 게시하지 않습니다.
- 음성은 작은 조각으로 전달하고 전체 크기·순서를 확인한 뒤 Storage에 직접 업로드합니다. Vercel 요청 본문에 큰 음성 파일을 넣지 않습니다.
- 다운로드 회수는 전용 탭에서 사용자가 요청한 오디오 내보내기만 가로채 전달합니다. 다른 다운로드와 Google 인증 정보는 수집하지 않습니다. NotebookLM 화면 변경으로 실패할 수 있으며, 실제 회수 검증이 필요합니다.

## 배포

- 기존 PR #46의 테스트를 포함한 PR #47을 이어서 구현합니다. NotebookLM 외 유료 AI API를 호출하지 않습니다.
- 운영 DB에 `20261026090000_weekly_podcast_publication`과 `20261026090013_notebooklm_browser_production`을 적용했고, 파일명도 DB의 실제 기록과 맞췄습니다. 제작 기록은 활성 관리자만 접근합니다.
- `20261026090723_podcast_production_retry`는 중단된 제작 기록을 보존하면서 같은 주간호를 새 자료로 다시 만들 수 있게 합니다. 이 변경도 운영 DB에 적용했습니다.
- `publish_podcast_production_job`은 기존 게시 함수를 같은 트랜잭션에서 호출합니다. 동일 제작을 다시 완료해도 게시를 반복하지 않습니다.
- ZIP 다운로드 API의 서버리스 추적 목록에는 확장 파일 전체를 포함합니다.
- 이 구현은 서버가 Google에 로그인하는 방식이나 공식 NotebookLM API가 아닙니다. 브라우저가 꺼진 동안의 NotebookLM 입력·음성 회수는 실행하지 않습니다. 자동 주간 예약 생성은 활성화하지 않습니다.

## 검증 기록 (2026-10-26)

- 실제 로그인된 Chrome에서 `notebooklm.google.com`이 `notebook.google.com`으로 연결되는 것을 확인했습니다.
- 새 시험용 노트북에서 공개 시험 자료 붙여넣기 → 한국어·심층 분석·맞춤 지시문 → 생성 시작을 확인했습니다.
- 시험 음성 **EU 사법재판소 왓츠앱 소송 자격 인정**, **5분 44초** 생성 완료 및 재생 화면을 확인했습니다. 실제 주간호로 공개하지 않았습니다.
- NotebookLM 플레이어는 HTML `audio` 요소를 제공하지 않았습니다. 따라서 내보내기 Blob을 회수하는 경로를 추가했습니다.
- 브라우저 도구의 다운로드 완료 대기가 시간 초과됐습니다. 확장 도구를 설치한 실제 생성→회수→업로드→게시 전 과정 성공은 아직 확인되지 않았습니다. 유닛 테스트나 화면 수동 조작을 전 과정 자동화 성공으로 표현하지 않습니다.
- 타입 검사·웹 빌드·새 동작 테스트 5개가 통과했습니다. DB 트랜잭션 안에서 미완성 차단·자료 변경 차단·게시 원자성·중복 방지·비로그인 차단을 확인한 뒤 모두 롤백했습니다. 새 제작 기록·주간호·오디오 게시 기록은 각 0건입니다.
- 자동 회수 실패 시 같은 제작 기록에 오디오 파일을 직접 연결하는 복구 경로를 제공합니다.
