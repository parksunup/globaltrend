## 검수 순서와 남은 쟁점

1. 한국 참고 규정의 판본을 먼저 확인합니다. 제2조·제7조의9·제32조의2·제37조의2·제75조의 이전 문구 5개와 제28조의12~15의 추가 규정 4개입니다. [차이 기록](../data/legal/sources/pipa-edition-reconciliation-20261117.json)과 [기존 제출본 보존 파일](../data/legal/official/pipa-preserved-20261117.json)에 원래 내용을 남겼습니다. 별도 판본·시행일을 확인하기 전에는 현재 적용 법문으로 단정하지 않습니다. 참고 내용은 읽을 수 있고, 현행 법문 통합검색 색인에서는 제외됩니다.
2. 일본 개정 초안을 원문과 대조합니다. 제2조 제8항, 제63조 제1항, 제22부칙 묶음 제2~4조와 일본 18개 비교 기준을 각각 확인합니다. 원문 1,327개 구조 노드의 기계적 대조는 한국어 의미 검수를 대신하지 않습니다.
3. 캘리포니아는 감독기관의 2026-01-01 시행 편찬 PDF를 확보했지만, 주 의회 법전 직접 대조는 403 확인 화면으로 미완료입니다. [직접·일반 브라우저 진단](../data/legal/sources/direct-source-diagnostic-20261117.json)을 참고합니다. 직접 대조가 안 된 상태를 ‘최신성 모두 확인’으로 표시하지 않습니다.
4. 7개 법률의 전문과 126개 비교 셀을 각각 검토합니다. 조건·예외·조항 번호·판본·경과규정을 확인하며, 별도 하위법령·지침·판례의 현행성까지 자동 점검했다고 해석하지 않습니다. 중국의 새 법률이 별도 DB 항목으로 게시되는 경우도 별도 확인 대상입니다.
5. 사람이 번역과 비교표 검토를 모두 끝낸 사건만 실제 커밋·원문 해시와 연결해 검토 기록을 남깁니다. 기록 형식은 [기능 안내](./legal-amendment-watch.md#검토-기록)를 따릅니다. 형식 예시를 완료 기록으로 복사하지 않습니다.

## 운영 반영과 구분할 사항

이번 작업에서는 PR 병합·운영 배포·운영 reports 쓰기·발행을 하지 않았습니다. 운영 반영은 별도 절차입니다. main용 주간 workflow가 작성되어 있어도 병합 전 정기 실행이 활성화된 것은 아닙니다.

운영에서 기능을 도입한 뒤에는 월요일 09:30 KST 점검 실행, 기존 서버의 Actions 읽기 설정, 최신 artifact 연결, 팀 로그인과 공개 페이지 접근을 실제로 확인해야 합니다. 설정이 없으면 포함된 수동 점검 자료임을 표시하도록 구현했습니다. 이후 사람 검수와 발행 역시 각각 별도 단계입니다.

로컬 화면에서는 접근 제한·검토 패킷·한국 본문과 참고 규정의 구분·모바일 표시를 점검했습니다. 기존 커밋의 GitHub 자동 검사와 Vercel 배포 상태도 성공으로 확인했습니다. 원격 Preview 화면과 API의 `commitSha` 대조는 접속 제한이 해소된 뒤 확인할 항목으로 남깁니다.
