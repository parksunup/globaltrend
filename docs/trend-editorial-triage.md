# 동향 후보 1차 분류 기준

이 기준은 모든 수집 경로에 공통으로 적용합니다. 번역 초안 작성 전에 현재 원문 판본을 읽고 개인정보 관련성, 독자에게 전달할 중요도, 원문 본문의 사용 가능 범위를 판단합니다. 판정·원문·초안·발행은 서로 다른 단계입니다.

## 판정 기준

1. **원문에 근거해 작성:** 원문에서 확인되는 사실만 씁니다. 추가 자료가 없으면 간결하게 작성하고, 원문이 언급한 결정문·지침 링크는 독자가 확인할 수 있도록 둡니다.
2. **개인정보와 무관한 자료 제외:** 개인정보 보호, 처리, 데이터 보호 규제·집행·권리·기술·사고와 실질적으로 관련되지 않은 자료는 `irrelevant`로 분류합니다. 주변 문맥에 관련 용어가 한 번 등장하는 것만으로 관련성을 인정하지 않습니다.
3. **중요도 낮은 자료 제외:** 독자에게 전달할 제도·정책·집행·권리·위험 변화가 없는 홍보·행사 운영·모집·시상·일정 안내 등은 `low_significance`로 분류하고 이유를 기록합니다. 행사라는 형식만으로 제외하지 않습니다.
4. **기존 후보도 현재 판본으로 재확인:** 특히 PDPC 등 원문 추출기가 보완된 출처의 기존 미작성 후보는 현재 공식 페이지에서 다시 확인합니다. 이전 판본과 기록은 보존하고, 내용이 달라졌을 때만 새 판본을 만듭니다.
5. **핵심 첨부·링크만 확인:** 원문만으로 핵심 사실을 확인할 수 없을 때 결정문·지침·조사결과 등 필요한 근거를 확인합니다. 소셜·동영상·공유·뉴스레터·일반 메뉴 링크를 모두 열지 않았다는 이유만으로 초안 작성을 막지 않습니다.

## 판정과 초안 대기열

- `accepted`는 현재 판본을 읽고 초안 작성 대상으로 판단했다는 뜻입니다. 초안이 작성·검수·발행되었다는 뜻은 아닙니다.
- `irrelevant`와 `low_significance`는 미작성 작업을 대기열에서 제외합니다. `needs_review`는 추가 판단이 필요하다는 뜻입니다.
- 기존 원고가 있는 자료는 기존 원고를 덮어쓰지 않습니다.
- 명시적으로 수락된 현재 판본에 연결된 미시도 취소 작업만 다시 대기열에 넣습니다. 이전 판본·시도된 작업·기존 원고가 있는 자료는 자동으로 재개하지 않습니다.
- 확인되지 않은 게시일은 비워 둡니다. 날짜는 개별 초안의 기술적 작성 가능 여부를 결정하지 않으며, 정확한 날짜가 필요한 주간호 편입에서만 확인합니다.
- `ai_ready`는 제목과 본문 텍스트가 있어 초안을 작성할 기술적 조건이 갖춰졌는지를 나타냅니다. 관련성·중요도·날짜 확실성·검수·발행 여부를 뜻하지 않습니다.

## 과거 운영 대조 기록

아래 수치는 **2026-11-14 당시의 스냅샷**이며 현재 대기열의 실시간 수치가 아닙니다. 당시 미작성 자료 626건을 현재 판본 기준으로 대조해 판정 누락과 판본 누락이 없음을 확인했습니다. 결과는 `accepted` 287건, `irrelevant` 160건, `low_significance` 179건이었습니다. 이 대조에서 기존 보고서와 공개 상태를 수정·삭제·발행하지 않았습니다.

당시 PDPC 기존 후보 54건은 최신 추출 경로로 재확인했습니다. 취소 상태였지만 현재 원문 판본을 명시적으로 수락한 미시도 작업 4건을 재대기열에 넣었습니다. 일회성 재수집·재대기열 작업은 이미 수행된 운영 조치이므로 마이그레이션 재실행 대상으로 삼지 않습니다.
