# 공개 페이지 이용률 통계 기획

## 알고 싶은 수치

- 메뉴별 방문 수와 이용자 수, 날짜별 추세
- 국가별 법제 비교·조문 열람 수
- 국가별 동향 열람 수와 주제별 열람 수. 한 동향이 여러 국가·주제에 걸치면 각각에 집계하고 전체 합계와 구분한다.
- 주간호·팟캐스트별 조회와 재생 시작 수, 자가진단 시작·완료 수, 상담소 다운로드 클릭 수
- 동향 검색·통합 검색별 검색 횟수, 선택한 국가·주제·기간 필터, 검색 결과 없음 비율, 결과 클릭 수

## 수집과 집계

기존 `/api/public/visitors`는 일별 방문자 수를 계산한다. 여기에 공개 화면에서 발생한 사건을 기록하는 API를 추가한다. 메뉴 진입, 상세 열람, 검색 제출, 결과 클릭, 자가진단 완료처럼 사용자가 실제로 한 행동만 기록한다. 화면 이동이나 새로고침으로 중복 전송할 수 있으므로 방문별 이벤트 ID로 중복을 제거한다.

서버는 자료 ID와 메타데이터를 공개 DB에서 조회해 국가·주제를 확정한다. 클라이언트가 보낸 국가·주제 값을 집계의 근거로 그대로 사용하지 않는다. 이벤트 원본과 날짜별 집계표를 분리해 대시보드가 긴 원본 목록을 매번 읽지 않게 한다. 한국 시간 기준 일·주·월별 집계를 만들고 기존 방문자 수와 같은 화면에서 비교한다.

검색어 원문에는 개인정보가 들어갈 수 있다. 검색 횟수·필터·결과 수는 기본 집계하고, 인기 검색어는 연락처·식별자 제거와 최소 출현 횟수 적용 뒤에만 표시한다. 원문 저장 기간과 열람 권한은 운영 전 확정한다. 관리자 화면에는 집계 결과를, 원본 기록에는 제한된 권한을 둔다. 공개 페이지에서 통계 원본을 읽을 수 없게 한다.

## 화면

작업실의 `이용 통계` 화면에 기간 선택과 메뉴별 추세를 먼저 둔다. 이어서 국가별 법제, 국가별·주제별 동향, 주간호·팟캐스트, 검색 사용 현황을 보여준다. 각 수치는 `조회`, `방문자`, `클릭`의 뜻을 구분해서 표시한다. 자료가 없는 날은 0으로, 수집에 실패한 날은 미확인으로 표시한다.

## 도입 순서와 확인

1. 이벤트 이름·경로·자료 ID와 검색 집계 항목을 확정한다.
2. DB 테이블, 제한된 쓰기 API, 일별 집계 작업을 만든다.
3. 공개 화면의 실제 사용자 행동에 이벤트를 연결한다.
4. 작업실 통계 화면에서 각 이벤트의 원본과 집계가 맞는지 대조한다.
5. 집계가 누락되거나 지연될 때 표시할 상태와 재집계 절차를 마련한다.

이 문서는 구현 기획이다. 현재 운영 중인 이용률 통계 기능을 설명하지 않는다.
