# 공개 동향의 읽기 안내

2026-11-26 · 별도 ‘질문으로 탐색’ 화면과 메인·메뉴 진입점을 제거하고, 기존 통합 검색을 기본 탐색 경로로 사용합니다.

## 현재 이용 흐름

- 공개 사이트의 통합 검색에서 질문이나 주제를 입력해 동향과 법제 자료를 함께 찾습니다.
- 동향 상세의 ‘이 동향에서 확인할 사항’은 해당 주제의 검색어와 국가 조건을 통합 검색으로 전달합니다.
- 질문 주제 정의와 동향 관련성 안내는 `lib/public-learning.ts`에 남아 있습니다. 사건별 적용 법률을 확정하거나 새 법률 요약·번역을 만들지 않습니다.
- 법제 비교는 기존 국가별 법제 화면을 사용하며, 기존 비교 자료의 검수 상태·예외·판본을 바꾸지 않습니다.

## 안내의 범위

동향 제목·요약·주제 표시의 표현을 바탕으로 관련 읽기 질문을 제안합니다. 일치하는 표현이 없으면 임의의 질문을 사건에 연결하지 않습니다. 사건에 적용되는 법이나 조항을 확정한 것으로 표시하지 않습니다.

공개 동향과 법제 로더를 사용하며 운영 DB나 미발행 원고를 직접 수정·발행하지 않습니다. 자료 없음과 연결 장애를 구별하고, 서버의 내부 오류 내용은 이용자에게 노출하지 않습니다.
