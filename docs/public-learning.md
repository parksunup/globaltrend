# 생활·업무 질문에서 시작하는 공개 탐색

2026-11-05 · 직원과 일반인이 같은 자료를 서로 다른 깊이로 읽도록 공개 화면을 보완했습니다.

## 이용 흐름

- `/public`: ‘궁금한 질문으로 시작해 보세요’에서 여섯 가지 질문을 고릅니다.
- `/public/explore?topic=children&audience=everyday`: 생활 속 확인 질문을 읽습니다. `audience=work`는 업무에서 확인할 질문을 표시합니다.
- 국가·지역을 선택하고 ‘선택한 국가로 보기’를 누르면 선택이 URL에 남습니다. 현재 등록된 일곱 법제를 모두 선택할 수 있습니다.
- 해당 기준의 기존 비교 요약·조건·예외·선택 판본·검토 기록을 읽고, 전체 비교표나 실제 연결되는 조문과 공식 근거로 이동합니다.
- 질문과 주제가 연결되는 공개 동향을 읽습니다. 동향 상세의 ‘나와 어떤 관련이 있나요?’에서 생활·업무 관점을 바꾸고 비교로 이어갑니다.

질문은 역외 적용, 아동 개인정보, 국외이전, 정보주체 권리, AI 서비스의 개인정보 이용, 유출 등의 통지·신고를 다룹니다. AI 질문의 비교 기준은 개인정보 이용 근거이며, AI에 관한 모든 법규를 포괄한다고 표시하지 않습니다.

## 내용과 근거의 범위

`lib/public-learning.ts`는 쉽게 읽기 위한 안내와 확인 질문, 탐색 경로를 정의합니다. 사건별 법률 판단·새 법률 요약·새 번역을 생성하지 않습니다. 동향 제목·요약·주제 표시의 표현을 바탕으로 관련 질문을 제안하며, 사건에 적용되는 법이나 조항을 확정한 것으로 표시하지 않습니다. 일치하는 표현이 없으면 임의의 질문을 사건에 연결하지 않습니다.

법제 카드의 요약·예외·판본·검토 기록은 기존 공개 법제 자료를 그대로 표시합니다. 공식 원문과 조문 연결은 기존 법제 읽기 도구를 사용합니다. 새 화면을 만들었다는 이유로 미검토 자료를 검수 완료로 바꾸지 않습니다. 공개 동향 로더를 사용하며 운영 DB나 미발행 원고를 직접 수정·발행하지 않습니다.

비교 자료의 미공개, 공개 자료가 없는 경우, 연결 장애를 구별합니다. 자료가 없다는 표시를 해당 규정이 없다는 뜻으로 사용하지 않습니다. 서버의 내부 오류 내용은 이용자에게 노출하지 않습니다.

질문·관점·국가는 URL로 공유할 수 있습니다. 질문 탐색 링크의 자동 사전 로딩은 끄고 선택할 때 자료를 읽어, 여섯 질문의 법제·동향을 미리 모두 요청하지 않도록 했습니다.

## 검증 범위

회귀 검사는 실제 기준 ID 연결, 입력값 검증과 URL 복원, 주제 표현의 일치·불일치, 생활·업무 전환, 요약·예외·검토 기록 보존, 실제 조문 앵커 연결, 자료 없음과 장애의 구별을 확인합니다. 실제 화면/API 확인과 로컬 시험 자료를 사용한 검증은 구별해 보고합니다. 기존 원고·비교표·번역의 사실·법률 검수를 새로 완료했다는 뜻은 아닙니다.
