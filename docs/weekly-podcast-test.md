# 주간 팟캐스트 제작 테스트

경로: `/public/weekly/podcast-preview` (제작 테스트 전용)

예시 주간 동향 7건에서 미리 작성한 대본을 구성하고, Gemini TTS는 두 화자의 WAV 음성 합성에만 사용합니다. Gemini로 요약이나 대본을 생성하지 않습니다. 사용자가 버튼을 눌렀을 때만 요청하며, 실제 주간호·공개 목록·저장소에는 게시하지 않습니다.

## 무료 등급으로 시험하기

음성 생성 API는 기본적으로 잠겨 있습니다. 아래 설정을 모두 하기 전에는 Gemini에 요청을 보내지 않습니다.

1. Google AI Studio에서 결제 계정을 연결하지 않은 무료 프로젝트를 사용합니다.
2. Vercel Preview 환경변수에 그 프로젝트의 `GEMINI_API_KEY`를 등록합니다. 키를 브라우저 코드나 Git에 넣지 마세요.
3. 같은 Preview 환경변수에 `GEMINI_API_FREE_TIER_CONFIRMED=true`를 설정합니다. 이는 담당자가 무료 프로젝트임을 확인한 후에만 설정하는 명시적 활성화 스위치입니다.
4. `gemini-3.8-flash-lite-tts`가 해당 프로젝트 무료 등급에서 활성화됐는지 Google AI Studio에서 확인합니다.
5. 무료 한도 초과(429), 접근 거부(403), 네트워크 오류가 나면 작업을 멈춥니다. 유료 모델이나 유료 프로젝트로 재시도하지 않습니다.

애플리케이션은 Google 프로젝트의 결제 연결 여부나 실제 무료 quota 잔량을 조회하거나 강제할 수 없습니다. 활성화 스위치는 실수로 API 키만 넣어 호출하는 것을 막는 확인 절차이며, Google 측 결제 상태를 기술적으로 검증하지는 않습니다. 따라서 결제 계정이 연결된 키에는 스위치를 켜지 마세요. 무료 프로젝트를 확인할 수 없다면 스위치를 설정하지 않은 채 대본만 검토하세요.

## 확인 사항

- API 키가 없거나 활성화 스위치가 꺼져 있으면 음성 요청은 503으로 중단됩니다.
- 무료 한도 초과나 접근 거부는 중단하고 유료 대체 호출을 하지 않습니다.
- 오디오는 사용자 요청으로 메모리에 생성해 바로 재생하며 서버 저장소에는 게시하지 않습니다.
- 페이지와 대본은 테스트 예시이며 정식 주간호로 표시하거나 연결하지 않습니다.
