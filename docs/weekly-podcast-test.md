# 주간 팟캐스트 제작 테스트

> 이 문서는 이전의 주요 소식 2건 실험 기록입니다. 현재 제작 구성은 메인 주제 1건과 선택적인 짧은 소식 1건입니다. 현재 실행·검증 범위는 [NotebookLM 제작 연결](./notebooklm-browser-pipeline.md)을 따릅니다.

경로: `/public/weekly/podcast-preview` (제작 테스트 전용)

혼합 시기의 예시 동향 중 주요 소식 2건을 골라 깊이 있는 대화로 구성하고, 사법재판소 판결 1건은 짧은 메모로 덧붙였습니다. 실제 한 주의 주간호가 아니며, 공개 동향 목록이나 발행 자료에 연결되지 않습니다. 각 소식의 상태(의견수렴·최종 지침·법원 절차 판단)를 분리해 다룹니다.

대본은 확인된 동향 자료에 근거해 코드에 직접 작성했습니다. Gemini는 승인된 대본의 두 화자 음성 합성에만 쓰이며, 요약이나 대본을 생성하지 않습니다. 작성 원칙과 검수 절차는 [주간 팟캐스트 편집 지침](./weekly-podcast-editorial-guide.md)에 있습니다.

## NotebookLM 벤치마크

[NotebookLM 벤치마크 노트북](https://notebook.google.com/notebook/a3032a4c-b66c-40e2-9599-13c9b3df1a4b)에서 EDPB 공식 자료 2건과 사법재판소 보도자료 1건을 출처로 선택해 한국어 **심층 분석** 오디오 오버뷰를 실제 생성했습니다. 생성된 오디오는 28분 5초이며 제목은 「EU 과징금 지침과 왓츠앱 판결」입니다. NotebookLM 화면의 오버뷰 요약은 과징금 판단 방법론과 DSA–GDPR 지침을 중심으로 구성됐습니다. 오디오 전체의 대본이나 세부 발화는 확인하지 않았으므로, 여기서는 두 호스트의 대화 형식과 출처를 중심으로 이야기를 선택하는 방식을 참고합니다. 28분이라는 길이를 주간 팟캐스트 목표로 그대로 가져오지는 않습니다.

이 프로젝트는 NotebookLM 오디오를 자동 복제하는 구조가 아닙니다. 사실관계를 확인하고 대본을 검토 가능한 형태로 유지하기 위해 Codex가 대본을 작성하고, Gemini TTS만 목소리를 입힙니다.

## 무료 등급으로 시험하기

음성 생성 API는 기본적으로 잠겨 있습니다. 아래 설정을 모두 하기 전에는 Gemini에 요청을 보내지 않습니다.

1. Google AI Studio에서 결제 계정을 연결하지 않은 무료 프로젝트를 사용합니다.
2. Vercel Preview 환경변수에 그 프로젝트의 `GEMINI_API_KEY`를 등록합니다. 키를 브라우저 코드나 Git에 넣지 마세요.
3. 같은 Preview 환경변수에 `GEMINI_API_FREE_TIER_CONFIRMED=true`를 설정합니다. 담당자가 무료 프로젝트임을 확인한 뒤에만 쓰는 명시적 활성화 스위치입니다.
4. `gemini-3.8-flash-lite-tts`가 해당 프로젝트 무료 등급에서 활성화됐는지 Google AI Studio에서 확인합니다.
5. 무료 한도 초과(429), 접근 거부(403), 네트워크 오류가 나면 멈춥니다. 유료 모델이나 유료 프로젝트로 대체 호출하지 않습니다.

애플리케이션은 Google 프로젝트의 결제 연결 여부나 실제 무료 quota 잔량을 조회하거나 강제할 수 없습니다. 활성화 스위치는 실수로 API 키만 넣어 호출하는 일을 막는 확인 절차이며, Google 측 결제 상태를 기술적으로 검증하지는 않습니다. 무료 프로젝트를 확인할 수 없다면 스위치를 설정하지 않은 채 대본만 검토하세요.

## 확인 사항

- API 키가 없거나 활성화 스위치가 꺼져 있으면 음성 요청은 503으로 중단됩니다.
- 무료 한도 초과나 접근 거부는 중단하고 유료 대체 호출을 하지 않습니다.
- 오디오는 사용자가 버튼을 눌렀을 때 메모리에 생성해 재생하며 서버에 저장하거나 자동 게시하지 않습니다.
- 페이지와 대본은 제작 테스트이며 정식 주간호나 공식 발행물로 인용하지 않습니다.
