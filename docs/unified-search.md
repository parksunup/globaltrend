# 공개 자료 통합검색

2026-11-09 구현. 최신 main 6153bde에서 시작했으며 다른 담당자의 미병합 질문 탐색 브랜치를 가져오지 않았습니다.

## 이용 흐름과 검색 범위

메인의 작은 안내 → `/public/search` → 질문 입력 또는 여섯 빠른 질문 → 동향과 법제 결과 → 전체 자료·공식 원문으로 이어집니다. 동향 상세에 별도 법제 탐색 안내를 추가하지 않습니다.

- 검색창·범위·방식·국가·주제·동향 게시일·동향 정렬·페이지는 URL에 남습니다. 법률 전문에서 돌아와도 조건을 유지합니다.
- 동향은 공개 reports만 읽습니다. 법제는 공개 law_versions와 기존 공식 한국법 자료만 읽으며 Preview에서도 저장소 미공개 초안을 대체 자료로 사용하지 않습니다.
- 법제 비교 요약에는 조건·예외를 포함하고, 조문은 원래 조항 단위로 검색합니다. 검색용 요약문으로 번역 전문을 덮어쓰지 않습니다.
- 동향 날짜는 원문 게시일이며 법제에는 판본을 표시합니다. 날짜 필터는 동향에만 적용합니다. 일부 자료를 읽지 못하면 장애를 표시하고 다른 자료의 검색을 계속합니다.
- 검색 결과에서 연 법제 비교·전문도 공개 판본을 유지합니다. 발행 취소 자료는 매 요청의 공개 목록에서 제외됩니다. 임베딩 응답에 과거 자료 ID가 남아 있어도 현재 목록에 없으면 무시합니다. 검토 메모·초안·내부 조사 기록은 검색 대상으로 보내지 않습니다.

## 현재 동작과 의미 검색의 차이

기본 모드는 단어 점수와 여섯 주제의 사전 정의 관련 표현을 결합합니다. 정확한 법률명·조문·제목을 우선하고, 관련 표현으로 연결된 결과에는 그 이유를 표시합니다. 이것만으로 임의의 질문 뜻을 이해한다고 표현하지 않습니다. ‘단어만’ 모드는 관련 표현과 임베딩을 모두 끕니다.

선택 임베딩 서비스가 실제 연결되어 유효한 응답을 준 경우에만 의미 검색 사용을 표시합니다. 점수는 법적 적용 여부나 답변의 확실성 비율이 아닙니다. 잘못된 URL, 타임아웃, 과도한 요청·응답, 잘못된 점수는 단어·관련 표현 검색으로 안전하게 전환합니다.

## 선택적 자체 CPU 임베딩

Node 앱은 유료 모델 API를 호출하지 않습니다. 선택 서비스 예시는 `scripts/search/embedding_server.py`이며 multilingual-e5-small로 공개 자료를 임베딩합니다. 실제 내려받는 모델 판본의 라이선스와 이용 조건을 운영 전에 확인해야 합니다. 라이브러리·모델을 무료로 이용할 수 있어도 서버·메모리·트래픽 비용까지 무료라는 뜻은 아닙니다.

```sh
python -m venv /tmp/globaltrend-search-venv
/tmp/globaltrend-search-venv/bin/pip install -r scripts/search/requirements.txt
# 이미 검증해 내려받은 로컬 모델을 권장합니다. 기본 실행은 다운로드하지 않습니다.
/tmp/globaltrend-search-venv/bin/python scripts/search/embedding_server.py --model /path/to/multilingual-e5-small
# 네트워크와 라이선스 확인 후 모델 다운로드를 명시적으로 허용할 때만:
# ... embedding_server.py --allow-download
```

Next 서버 환경 변수 `PUBLIC_SEARCH_EMBEDDING_URL=http://127.0.0.1:8766/search`로 연결합니다. 다른 호스트는 HTTPS와 `PUBLIC_SEARCH_EMBEDDING_TOKEN`을 사용하세요. 이 토큰은 서버 전용입니다. 로컬 호스트는 개발 환경 예시이며 Vercel의 localhost가 개발 PC를 가리키지 않습니다. Vercel에서 쓰려면 접근 가능한 별도 서버가 필요합니다. 모델 다운로드를 서버 요청 처리 중에 실행하지 않습니다.

공개 자료 내용으로 해시를 만들고 최근 두 자료 묶음만 메모리에 유지합니다. 긴 조문은 임베딩 계산에서만 토큰 단위로 겹쳐 나누며 결과는 원래 조문에 묶습니다. DB·pgvector·영구 색인은 만들지 않습니다. 자료/본문이 바뀌면 다시 계산하므로 최초 요청이 느릴 수 있습니다. 앱의 기본 2.5초 제한과 CPU 속도에 따라 의미 검색이 자주 대체될 수 있어 운영 전 실제 자료 규모로 지연 시간·메모리·관련도 평가가 필요합니다. 최대 문서 6,000개·임베딩 조각 12,000개·요청 6MB로 제한합니다. 매 요청 공개 문서 목록 전송 역시 큰 자료에서 한계가 있습니다.

현재 개발 환경에서는 Hugging Face 모델 파일 호스트 접속이 정책상 차단되었습니다. 실제 모델 다운로드·추론·다국어 관련도 평가는 완료하지 않았습니다. 연결 계약·오류 처리·본문 변경 시 캐시 무효화는 오프라인 테스트로 확인하며, 이를 실제 의미 검색 품질 검증으로 간주하지 않습니다.

## 검증

`npm test`, `npm run typecheck`, `npm run validate:data`, `npm run build`, `node scripts/verify-content-traces.mjs`와 `python -m unittest discover -s tests -p 'test_search_embedding.py'`를 실행합니다. JS는 질의/필터·공개 범위·결과 화면·실패 처리를, Python은 다운로드 없이 프로토콜·인증·캐시를 검사합니다. 브라우저 검증에는 운영 DB 대신 별도 로컬 공개 자료 fixture를 사용합니다.
