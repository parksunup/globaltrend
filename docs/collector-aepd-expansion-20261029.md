# AEPD 공식 보도자료 출처 추가 — 2026-10-29

- 스페인 개인정보 감독기관 AEPD의 보도자료 목록, 각 기사 제목·공식 게시일·본문을 확인했다. 목록에서 `more-link`의 문구 대신 카드 제목을 사용한다. 게시일은 목록과 상세의 `time[datetime]`을 대조한다.
- 공식 `robots.txt`가 보도자료 목록의 `?page=` 페이지 이동을 금지한다. Edge는 허용된 첫 목록 페이지만 조회하며 페이지 링크를 따라가지 않는다. 첫 페이지에서 확인할 수 없는 발표 자료까지 모두 수집했다고 주장하지 않고 기존 `coverage_complete=false` 및 `listing_exhaustiveness_unverified` 기록을 유지한다. 날짜가 3일 범위에 있더라도 첫 페이지 밖의 자료는 누락 가능성이 있다.
- 공식 RSS `/noticias/feed.xml`은 2026-10-29 확인 시 최신 항목이 7월로, 10월 보도자료를 포함하지 않았다. RSS를 목록 대체 수단으로 쓰지 않는다. 실제 상세 한 건의 본문과 2026-10-19 게시일을 확인했다. 다른 목록 첫 항목은 한 차례 HTTP 500으로 실패했으므로 실패 URL은 기존 backlog를 통해 재시도한다.
- 기존 18개 활성 출처, EDPS·EUR-Lex 보류, 한국시간 실행일과 직전 이틀의 일일 수집, 보존 후 한국어 작성·검사·/work 제출, 주간 약 8건 선정과 사람 검수 후 발행 절차는 유지한다. 새 출처의 실제 일일 실행 및 제출은 등록·배포 이후 별도 실행 증거로 판정한다.
