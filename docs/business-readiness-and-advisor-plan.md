# 기업 해외 진출 개인정보 자가진단 및 상담 기능 실행안

상태: 별도 브랜치에서 웹 자가진단과 데스크톱 앱 구현 중 · 2026-11-21
작업 브랜치: `codex/business-privacy-checklist` (origin/main 기준)

## 사용자가 원하는 결과

해외 진출을 준비하는 기업이 진출 대상 국가의 개인정보 보호 의무를 질문에 답하며 점검하고, 결과와 보완 과제를 쉽게 확인합니다. 별도 시범 상담 앱은 공개된 해외법 설명자료와 상담 사례집을 근거로 답하고, 인용한 자료를 답변에서 확인할 수 있어야 합니다. OpenAI API 키를 사이트 운영자가 대신 부담하지 않으며, 가능하면 이용자가 자기 ChatGPT 계정·요금제를 사용합니다. 앱 설치파일은 국제요정 사이트에서 내려받을 수 있게 합니다.

## 저장소에서 확인한 출발점과 주의점

- 공개 사이트에는 국가별 법제 번역 및 비교 화면과 17개 비교 기준 × 7개 법제 자료가 있습니다.
- 기존 7개 법제 번역은 프로젝트 리드 확인에 따라 사람 검수 완료입니다. 번역의 검수 상태와 새 자가점검의 질문별 조항 연결은 별도로 관리합니다.
- 별도 브랜치에 국가 선택과 단계별 응답을 갖춘 공개 자가점검 페이지, 11개 질문 × 7개 관할권(77개 매핑), Electron 앱 기반이 있습니다. 기존 번역을 미검수로 표시하지 않으며, 직접 대응하는 법률 개념이 없는 경우에는 근거가 없다고 하지 않고 제도 차이와 관련 조항을 안내합니다.
- Electron 앱은 이음오피스/OpenOffice의 Apache-2.0 ChatGPT 직접 연결 구조를 기준으로 OAuth·PKCE, 로컬 콜백, 토큰 갱신·폐기를 구성했습니다. 아직 실계정 승인과 근거 기반 상담의 전체 흐름을 확인하지 않았으며, 서명 설치파일도 없습니다.
- OpenAI 공식 가이드상 오픈소스·로컬 앱은 Sign in with ChatGPT의 eligible Responses API 요청에 이용자의 ChatGPT plan 사용을 요청할 수 있습니다. 공개 원격 호스팅 웹사이트에서 같은 기능을 제공하는 것은 현재 선정된 상용 파트너의 제한 시험입니다. 승인을 전제하지 않습니다.

## 질문-조항 연결 상태 바로잡기

77개 질문-관할 연결 중 현재 `candidate`로 기록된 연결은 72개이고, 5개는 제도가 직접 대응하지 않아 `notDirectlyComparable`로 설명합니다. “근거 공백 7개”라는 표현은 정확하지 않습니다. 직접 대응하지 않는 5개는 미국 캘리포니아의 일반 법적 근거, 싱가포르의 민감정보 특별범주, 캘리포니아의 GDPR식 국외이전 체계, 일본의 자동화 결정 권리, 싱가포르의 자동화 결정 권리입니다. 이는 관련 규율·차이를 설명하는 항목이지 법제 번역의 검수 누락이 아닙니다.

별도로 확인한 두 캘리포니아 항목은 조항을 보완 연결했습니다. 보유기간·보안에는 CCPA와 California Civil Code §1798.81.5를 연결했고, 침해 통지는 CCPA의 민사상 구제 조항과 별개인 California Civil Code §1798.82를 연결했습니다. 이 작업은 기존 사람 검수 완료 번역 상태와 분리됩니다.

## 병렬로 진행할 수 있는 작업

| 작업 묶음 | 산출물 | 다른 작업과의 경계 |
| --- | --- | --- |
| A. 진단 기준·문항 | 7개 법제에 공통인 질문, 법률별 분기, 판정·보완 안내, 근거 원문 연결표 | 질문 데이터와 법제 근거만 작성. UI/API 구현과 분리 |
| B. 웹 자가진단 화면 | 국가 선택 → 한 번에 한 질문 → 결과 요약 → 보완 과제·근거 확인 | 공개 경로와 프론트엔드만 구현. 질문·판정 규칙은 A의 데이터 계약을 소비 |
| C. 상담 앱·ChatGPT 연결 검증 | IeumOffice 패턴의 로컬 앱, Sign in with ChatGPT 동의·세션·Responses 요청, 자료 검색 및 인용 | 웹 진단 코드와 분리. OAuth 토큰은 장치 밖으로 보내지 않음 |
| D. 지식자료·검수 | 공개 법 설명자료·상담 사례의 출처 목록, 이용조건, 구조화·인용·갱신 절차 | 상담 앱 실행 구조와 분리. 데이터 이용권한 검토 및 법률 검수 |
| E. 배포·다운로드 연결 | 릴리스 파일, 버전·지원 OS·설치 안내, 국제요정 다운로드 화면 | 실제 설치파일이 만들어지고 서명·악성코드 확인이 끝난 뒤 연결 |

A와 B, C와 D는 서로 다른 파일·산출물을 맡아 병렬 진행할 수 있습니다. B는 A의 질문 데이터 계약을 소비합니다. C는 D의 자료를 기다리지 않고 로그인·대화·근거 표시의 합성 fixture로 개발할 수 있지만, 실제 상담 품질은 D의 자료 연결 후에 확인합니다. E는 앱 패키징이 완료된 뒤 최종 설치파일 검증을 거쳐 연결합니다.

## 실행 순서와 완료 기준

1. **공통 계약 고정:** 7개 기존 법제 코드와 질문 데이터의 필드, 진단 결과의 의미, 인용 형식을 정합니다. 결과는 법률 자문이 아니라 위험 신호·추가 확인 항목으로 표시합니다.
2. **웹 진단 MVP:** 국가 선택, 단일 질문 진행, 이전·다음, 저장하지 않는 세션 응답, 결과별 근거/보완 안내를 만듭니다. 중간 응답은 기본적으로 브라우저에 장기 저장하지 않습니다.
3. **진단 기준 검수:** 각 문항의 적용 법제·공식 조문·예외·근거일을 교차 확인하고 전문가가 검토할 체크시트를 제공합니다.
4. **로컬 상담 앱 완성:** 사용자의 컴퓨터에 ChatGPT 앱을 설치할 필요 없이, 이음오피스에서 확인한 공식 계정 연결 흐름을 사용합니다. 외부 브라우저에서 승인하고 로컬 앱의 127.0.0.1 콜백으로 돌아옵니다. 실계정 로그인·권한 거부·만료·취소를 검증합니다.
5. **자료 기반 답변:** 이용이 허용된 법 설명자료와 상담 사례를 작은 출처 목록부터 넣고, 검색된 문서·페이지·문단을 매 답변과 함께 제시합니다. 자료에 답이 없을 때는 없다고 말하고 관할·시행일을 확인하도록 합니다.
6. **앱 다운로드:** Windows 우선 여부와 지원 버전을 확인한 뒤 패키지·서명·설치/삭제·업데이트를 재현하고, GitHub Releases 파일을 웹의 다운로드 페이지에서 제공합니다.
7. **웹 ChatGPT 통합 승인 병렬 신청:** 원격 호스팅 사이트에서 직접 ChatGPT plan을 사용하려면 OpenAI 상용 파트너 승인이 필요합니다. 신청 결과와 무관하게 로컬 앱 시범을 막지 않습니다.

## 지금 작업 브랜치에서 병렬로 실행하는 범위

- 별도 `codex/business-privacy-checklist` 브랜치에서 질문 데이터, 공개 웹 자가진단 MVP, 상담 연결 기반/데이터 계약 및 실행 순서를 준비합니다.
- 메인 브랜치, 운영 Supabase, 운영 발행자료, Vercel 배포를 수정하지 않습니다.
- 기존 법제 번역의 사람 검수 상태를 되돌리지 않습니다. 새 질문별 법제 연결은 번역 상태와 구분해 표시합니다.
- 사용자 ChatGPT OAuth 자격증명을 웹 서버에 보관하지 않습니다. 로컬 앱의 공식 OSS 흐름을 검증하며 상용 웹 승인은 별도입니다.
- 산출물은 우선 검토 가능한 PR을 목표로 합니다. 운영 배포·실제 앱 다운로드 공개는 근거 검색 연결, 실계정 확인, 설치파일 검증 뒤에 합니다.
