# 자료를 수정하고 공개하는 방법

## 사용하는 화면

`/work`가 동향과 법제를 함께 관리하는 작업 공간입니다. 자료 목록에서 종류·상태·검색어로 필요한 자료를 찾습니다. 기존 `/work/legal` 주소도 법제 필터가 선택된 같은 화면으로 이동합니다. `/team`은 제출 자료를 읽는 화면으로 유지합니다.

## 공개하기

1. 팀 계정으로 로그인합니다.
2. 공개할 자료를 선택합니다. 한 건만 공개하려면 제목을 눌러 ‘이 자료 공개’를 사용해도 됩니다.
3. 총괄 관리자는 ‘선택한 N건 공개’를 누릅니다. 등록·검수 대기·승인 버튼을 순서대로 누르지 않습니다. 편집자는 같은 목록에서 관리자에게 공개를 요청할 수 있습니다.
4. 완료 건수와 실패한 제목·이유를 확인합니다. 실패한 자료만 다시 시도할 수 있습니다.

처음 목록에서는 20건씩 보여 줍니다. ‘이 페이지 선택’과 ‘검색 결과 모두 선택’을 구분하며, 다수의 자료는 시스템이 100건씩 나눠 처리합니다. 선택한 뒤 다른 사람이 수정한 자료는 자동으로 바뀐 내용으로 공개하지 않습니다. 새 내용을 확인하고 다시 선택해야 합니다.

## 수정본과 공개본

제목을 누르면 공개될 모습, 내용 수정, 내부 기록을 볼 수 있습니다. 동향은 화면에서 제목·요약·본문·국가·주제를 수정합니다. 법제는 한국어 전문의 조문과 17개 기준의 요약·예외·관련 조항을 함께 수정합니다. 조문 번호·원문 출처·법률의 식별 정보는 임의로 바꾸지 않습니다.

‘수정본 저장’은 작업 공간에만 저장합니다. 이미 공개된 자료는 그대로 남습니다. 목록에 ‘공개 중 · 수정본 있음’이 표시되고 변경 전후를 볼 수 있습니다. 관리자가 ‘수정본 공개’를 눌러야 공개 내용이 교체됩니다. 이전 공개 내용과 검토 기록은 내부 이력에 보관합니다. 이미 검수한 동일 자료를 다시 검수했다고 체크할 필요는 없습니다.

## 공개 취소와 휴지통

관리자가 ‘공개 취소’를 누르면 공개 목록·검색·상세에서 내려갑니다. 원문, 작업본, 이력은 남습니다. 공개되지 않은 자료는 편집자도 휴지통으로 옮길 수 있습니다. 상태 필터에서 ‘휴지통’을 선택하고 복원하면 다시 수정·공개할 수 있습니다. 복원만으로 재공개되지는 않습니다.

## 새 자료

새 제출 자료도 같은 목록에 표시됩니다. 목록에서 선택해 공개하면 등록과 공개를 함께 처리합니다. 동향은 주간 예시호에 한정하지 않고 전체 편집 자료를 읽습니다. ‘새 자료’에서 직접 작성하거나 제출 자료로 입력창을 채울 수도 있습니다. 법제는 저장소에 제출한 번역 전문·비교표 묶음을 등록합니다. 같은 판본은 중복 등록하지 않습니다. 이미 등록된 내용이 제출 파일과 달라졌으면 자동 덮어쓰지 않고 최신 작업본을 확인하도록 안내합니다. 수집 성공·실패·원문 확인은 별도 ‘수집 상태’ 메뉴로 옮겼습니다. 수집기 실행 환경과 스케줄은 이번 변경에서 바꾸지 않습니다.

## 권한과 배포

- 관리자: 수정·공개 요청·공개·공개 취소·휴지통·복원.
- 편집자: 수정·공개 요청·비공개 자료의 휴지통·복원.
- 방문자: 공개 자료와 기존 제출 자료 열람. 작업본과 내부 이력은 팀 권한으로 보호합니다. 검수자·검수일은 공개 응답에서 제외합니다.

PR Preview는 실제 사이트에 저장하지 않는 화면 확인용입니다. 운영 사이트의 `/work`에서 실제 작업합니다. `publication_workspace_lifecycle` 마이그레이션과 앱 코드가 함께 필요합니다. 새 표의 RLS와 명시적 권한, 서버 액션과 DB 함수 모두에서 관리자 권한과 현재 revision을 검사합니다.

검증은 Node UI·서버 액션 테스트, 타입·데이터·빌드 검사, Supabase pgTAP와 실제 PostgreSQL의 저장→공개→취소→휴지통→복원 흐름을 포함합니다.
