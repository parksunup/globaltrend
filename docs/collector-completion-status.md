# 수집 회차 완료 판정

수집 결과의 `status`는 이번 회차에 설정된 목록과 발견한 자료의 처리가 끝났는지를 나타낸다. 목록의 마지막 페이지 또는 RSS의 현재 끝에 도달했고 현재 단계의 요청 실패가 없으면 `complete`(클라우드·Edge 이벤트에서는 `success`)로 기록한다. `collection_complete=true`도 함께 남긴다. 신규 자료가 0건이어도 정상 종료면 완료다.

`coverage_complete`는 더 강한 기간 범위 확인 결과다. 공식 기간 필터, 전체 날짜 보관 목록처럼 요청 기간을 확인한 경우에만 true로 둔다. 최근 항목만 제공하는 RSS는 회차를 완료할 수 있지만 과거 기간의 범위 확인은 별도로 남는다. 이 두 필드를 하나의 성공 여부로 합치지 않는다.

본문 실패는 URL과 재시도 위치를 기록한다. 목록에 있는 외부 링크를 처리하지 못하거나 페이지 요청이 실패하면 회차를 완료로 닫지 않는다. 게시일을 확인하지 못한 개별 자료는 `held` 및 `recovery_needed`에 남기되, 정상 처리된 다른 자료의 후속 작업은 진행한다. 연·월만 확인되는 게시일의 정밀도 표시는 후속 데이터 모델 변경이 필요하다.

이 판정은 `config/trend-collector.json`에 있는 37개 출처의 공통 실행 경로에 적용한다. 현재 활성 출처는 일반 Python 수집기, 클라우드 Python 작업자, Supabase Edge 작업자에서 실행된다. 비활성 또는 보류 출처는 실행 허용 상태를 별도로 따른다. 이 문서의 완료는 설정된 수집 경로의 이번 회차 종료를 뜻하며, 출처가 제공하지 않는 과거 자료는 복구 과제로 기록한다.
