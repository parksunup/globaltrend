# 검토 자료 공개 및 발행 절차 1차 개선

## 운영 반영 결과

2026-10-19 총괄 관리자의 대화 중 공개 승인에 따라 기존 편집 자료를 운영 DB에 발행했습니다. 검수자·검수일과 대화 승인 이력은 내부 기록으로 보관합니다.

- 동향 21건: 저장소의 전수 편집본 제목·요약·본문을 사용했습니다. 같은 원문으로 등록돼 있던 이전 초안은 내부 이력에 보존한 뒤 최신 편집본으로 갱신했습니다.
- 법제 7개, 비교표 119칸: 번역 전문 6개와 한국 공식 원문 색인을 같은 판본의 비교표와 함께 등록·발행했습니다.
- 기존 수집 초안 1건은 이번 승인 대상인 저장소의 21건에 해당하지 않아 초안으로 유지했습니다.
- 출처 9곳을 조회할 수 있습니다. 추가 출처는 수동 등록이며, 자동 수집 스케줄이나 수집 허용 설정을 켠 작업은 아닙니다.
- 검수자·검수일과 내부 JSON은 공개 HTML에 넣지 않으며, 익명·일반 로그인 계정의 해당 DB 열 조회도 제한했습니다.
- 활성 팀 편집자의 자료 수정·삭제 권한은 유지합니다. 승인·발행 상태로 올리는 작업은 DB에서도 관리자만 가능합니다.

공개 사이트는 `/public`, 동향 검색은 `/public/search`, 법제는 `/public/laws`입니다. 주간 예시호는 여러 시기의 자료를 묶은 예시이므로 정식 주간호로 바꾸지 않았습니다.

## 이번 PR의 화면 변경

등록된 동향·법제의 단건 또는 선택 일괄 공개를 추가했습니다. 한 번의 공개 동작으로 필요한 내부 상태 전환을 처리하며, 반복 체크를 요구하지 않습니다. 자료 목록을 먼저 보여 주고 새 글 작성·수집 상태는 접었습니다. 실패 자료 표시, 중복 발행 방지, 동시 수정 감지, 동일 법률의 복수 판본 선택 방지도 포함합니다.

전체 작업 공간 통합, 수정본 관리, 공개 취소·휴지통·복원은 [후속 기획안](publication-workflow-redesign.md)에 남겼습니다. 팀원의 수정·삭제 **화면**까지 이번 PR에서 완성한 것은 아닙니다.

## 검증

- 운영 DB의 비로그인 역할로 동향 21건·법제 7개·비교표 119칸 조회 확인.
- 운영 공개 홈·검색·법제·비교·주간호·출처 및 작업자 진입 경로 HTTP 200 확인.
- 번역 전문 6개와 공개 동향 상세 3건 HTTP 200·본문 포함 확인.
- 로컬 PostgreSQL에서 마이그레이션과 전체 발행 SQL 재실행, 중복 생성 없음 및 검수 메타데이터 접근 제한 확인.
- 서버 액션 10개를 포함한 Node 테스트 61개, TypeScript 검사, 데이터 검사, 빌드 검증.

로컬 브라우저 제어가 Work 설정에서 비활성화되어 있어 이번 점검은 실제 HTTP 응답·서버 액션 테스트·DB 검증으로 수행했습니다. 화면에서 클릭을 실행했다고 기록하지 않습니다.

## 파일 이력

공개용 비교표 복사본이 최신 원본과 달랐던 문제를 수정했습니다. `source-manifest.json`에는 가져왔을 때의 해시와 현재 복사본의 해시·원본 경로를 함께 남겨 원자료 이력과 이후 변경을 구분합니다.


## 검수 상태 표시 정정

운영 DB의 발행 기록과 별개로 제출 파일의 작성 당시 상태와 Preview 안내문에 남아 있던 미검수 표현을 정정했습니다. 작업자 목록·번역 전문·119개 비교 셀·공개 미리보기·조문 툴팁은 실제 발행 판본과 대조해 상태를 표시합니다. 동향은 동일 원문 URL뿐 아니라 제목·요약·본문·원제·날짜·국가·주제까지 같아야 발행 상태를 승계합니다. 법제는 패키지 해시와 실제 내용이 모두 일치해야 합니다. 조회 실패는 미검수로 단정하지 않고 상태 확인 필요로 표시합니다. 작성 당시 메모는 이력으로 구분하고, 원본 파일·해시는 유지했습니다. 새 작업본과 주간호 구성 예시는 자동으로 검수 완료 처리하지 않습니다.

표시 정정 회귀를 포함한 Node 테스트 90개, 타입 검사·데이터 전수 검사·배포 빌드를 통과했습니다.
