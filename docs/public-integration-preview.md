# 공개 화면 통합 테스트

이 브랜치(`codex/public-integration-preview`)는 공개용 화면에 두 담당자의 제출 자료를 붙인 검수용 시안입니다. 정식 발행이 아닙니다.

- 첫 화면 `/`: 기존 공개용 디자인. `/public`도 같은 내용을 보여줍니다.
- `/public/search`, `/public/trends/[id]`: 동향 담당 PR #16의 공식 출처 9곳에서 선정한 표본 21건을 검색하고 읽습니다.
- `/public/sources`: 수집 출처 9곳의 조사 상태와 표본 수를 보여줍니다.
- `/public/laws`: 법제 담당 PR #15의 법률 7개와 17개 기준 × 7개 법제 비교표 119칸을 보여줍니다.
- `/public/laws/appi`: 현재 제출된 APPI 전체 한국어 번역 초안을 공개용 디자인으로 읽습니다. 다른 법률의 전문 번역은 제출되지 않았으므로 만들어 보이지 않습니다.
- `/team`, `/legal-translation`: 기존 검수·피드백 화면입니다.

테스트 Preview에서는 모든 자료를 **사람 검수 전 초안**으로 표시합니다. 현재 실제 운영 공개 페이지는 DB에서 승인 후 발행된 보고서만 읽는 방식을 유지합니다. 이 브랜치는 PR #15·#16의 제출 파일을 2026-10-12에 복사한 **시점별 스냅샷**입니다. 담당자 브랜치에서 이후 자료를 고치거나 추가해도 이 테스트 브랜치에는 자동 반영되지 않으며, 다시 가져와야 합니다.

검증: `pnpm test`, `pnpm validate:data`, `pnpm typecheck`, `pnpm build`와 GitHub CI, Vercel Preview. 데이터베이스 쓰기와 정식 발행은 이 테스트에서 수행하지 않습니다.
