# 공개 화면 통합 테스트

> 아래는 2026-10-12의 PR #30 시안 기록입니다. 현재 통합본의 자료·첫 화면·DB 연결은 [네 PR 통합 안내](./integration/README.md)를 따릅니다. 아래의 ‘APPI만 있음’이나 첫 화면 설명은 현재 상태가 아닙니다.

이 브랜치(`codex/public-integration-preview`)는 공개용 디자인에서 두 담당자의 제출 자료를 함께 검토하는 시안입니다. 정식 발행 자료가 아닙니다.

- 첫 화면 `/`와 `/public`: 동향 표본, 법률 조사 현황, 실제 태그가 붙은 주제별 동향을 보여줍니다.
- `/public/search`: 동향 표본 21건을 검색합니다. 1·6·12개월 또는 직접 지정한 날짜 범위, 국가·지역, 주제로 좁힐 수 있습니다. 국가·지역 이름은 한국어로 표시하며 유럽연합은 ‘유럽연합(EU)’입니다.
- `/public/trends/[id]`: 동향 상세와 공식 원문을 확인합니다.
- `/public/laws`: ‘법률 전문’과 ‘법제 비교’ 두 화면입니다. 전문이 제출된 법률은 제1조부터 순서대로 읽고, 비교 화면에서는 17개 기준 × 7개 법제의 조사 초안 119칸을 비교합니다.
- `/public/laws/appi`: 현재 제출된 일본 APPI 한국어 번역 초안을 목차와 함께 읽습니다. 다른 법률의 전체 본문은 이 저장소에 아직 없으며, 준비 상태와 공식 원문 링크를 표시합니다.
- `/team`, `/legal-translation`, `/feedback`: 제출 자료·번역·저장된 피드백을 보는 검수 화면입니다. 공개 사이트의 메뉴·기사·조문에는 의견 작성 기능을 두지 않습니다.

‘수집 출처’는 공개 상단 메뉴에서 제외했습니다. 자료의 공식 출처 링크는 동향 상세에 남겨 둡니다. 출처 조사 파일과 기존 `/public/sources` 주소는 유지하되 공개 메뉴에서 연결하지 않습니다.

테스트 Preview에서는 모든 제출 자료를 **사람 검수 전 초안**으로 표시합니다. 실제 운영 공개 화면은 승인 후 발행된 DB 보고서만 읽습니다. 이 브랜치의 법제·동향 자료는 2026-10-12에 복사한 **시점별 스냅샷**입니다. 담당자 브랜치의 이후 변경은 자동으로 들어오지 않습니다.

검증: `pnpm test`, `pnpm validate:data`, `pnpm typecheck`, `pnpm build`, GitHub CI, Vercel Preview. 데이터베이스 쓰기와 정식 발행은 이 테스트에서 수행하지 않습니다.
