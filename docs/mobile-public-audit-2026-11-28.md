# 공개 페이지 모바일 점검 기록

2026년 11월 28일 공개 사이트 `https://globaltrend-six.vercel.app`의 주요 12개 경로를 Chrome의 390 × 844 및 320 × 690 모바일 화면에서 확인했다. 실제 CSS 뷰포트와 문서 너비를 함께 읽었고 모든 경로의 문서 너비는 각 뷰포트와 같았다. 메뉴 열기와 동향 검색 필터 펼치기도 클릭해 확인했다.

## 동적 화면 점검

- 320px에서 법제 목록의 한국·일본·중국·EU·영국·미국 캘리포니아·싱가포르 7개 버튼을 각각 클릭해 해당 법률 전문 제목과 링크가 바뀌는지 확인했다. 모든 상태에서 문서 너비는 320px이었다.
- 해당 상세 경로 `/public/laws/pipa`, `/appi`, `/pipl`, `/gdpr`, `/uk-gdpr`, `/ccpa`, `/pdpa`도 열어 각 제목과 조문 검색칸, 문서 너비를 확인했다. 일본·중국·EU·영국·캘리포니아·싱가포르 상세 제목에 `한국어 번역 초안`이 남아 있다. 기존 검수 완료 상태에 맞는 명칭으로 정리할 필요가 있다.
- 320px에서 일본·중국·EU·영국·미국 캘리포니아·싱가포르 6개 안내서 버튼을 각각 클릭해 제목이 바뀌는지 확인했다. 일본·영국·캘리포니아·싱가포르의 일부 표는 내부 콘텐츠 폭이 카드 폭보다 크다. 표의 부모에 가로 스크롤이 적용되어 문서 자체는 넘치지 않지만 가로로 읽어야 한다는 안내는 없다.
- 자가진단은 6개 지역을 각각 시작해 전체 문항에 답하고 결과 보기를 눌렀다. 일본 21문항, 중국 27문항, EU 17문항, 영국 18문항, 미국 캘리포니아 17문항, 싱가포르 29문항이다. 여섯 결과 모두 같은 페이지·결과 컴포넌트에 표시됐고 320px 문서 너비를 넘지 않았다. 일본 결과에는 전체 분포 막대와 상태별 수치, 추가 확인 항목 15개가 표시됐다. 추가 확인 항목이 한 열에 길게 이어져 결과 카드와 내려받기 버튼까지 이동 거리가 길다. 접기·지역별 이동 기능이 있으면 탐색이 수월해진다. 이번 시험은 각 문항의 첫 번째 응답을 선택했으며 모든 응답 조합을 시험한 것은 아니다.
- 동향 검색 첫 페이지에서 연결된 공개 상세 25건을 320px에서 모두 열어 본문 길이와 문서 너비를 확인했다. 짧은 사례 `/public/trends/4b9cf0cd-7e4c-499f-810c-828439a9a29d`는 `main` 텍스트 987자, 중간 사례 `/public/trends/1cfb53a3-0d8a-44ba-ad38-ad045f03034d`는 1,235자, 긴 사례 `/public/trends/7f07aacc-9707-42d6-8431-29b508e6915d`는 1,673자였다. 25건 모두 전역 가로 넘침은 없었다. 중간 길이 사례의 제목은 320px에서 네 줄, 높이 약 150px로 첫 본문 도달까지 스크롤이 길어진다.
- 메인 모바일 메뉴 열기와 동향 검색 필터 펼치기 클릭은 정상 동작했다.

## 점검의 한계

390px 및 320px 최초 화면과 문서 너비, 법제 7개 국가 및 상세, 안내서 6개 국가, 6개 지역의 자가진단 완료 화면을 확인했다. 문항 129개에 각각 한 응답을 골라 결과를 열었으나 다른 응답 조합에 따른 결과는 확인하지 않았다. 동향 상세는 검색 첫 페이지의 공개 25건을 열었다. 나머지 동향 상세, 검색 결과의 모든 카드, 긴 안내서의 모든 표를 일일이 시각 검토하지 않았으므로 개별 동향·문항 조합 전체의 결함이 없다는 뜻은 아니다.
