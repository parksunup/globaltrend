# 해외 개인정보 보호법 준수 안내서

공식 감독기구·법령기관이 기업/조직을 위해 공개한 준수 안내자료를 관할별로 모읍니다. 각 Markdown 파일은 원문을 확인해 한국어로 구조화한 학습본이며, 원문을 그대로 복제한 번역본은 아닙니다. 공식 원문 PDF/페이지, 기준일, 버전, 문서별 완독 여부, 페이지·절 대응표를 함께 기록합니다.

이번 범위는 한국을 제외한 국제요정 번역본 6개 해외 관할입니다. 이전 자가진단 질문 설계는 이 안내서 수집·정리 작업의 입력으로 사용하지 않습니다.

| 관할 | 주 안내서 학습본 | 원문 및 검토 현황 |
|---|---|---|
| 일본 APPI | [일본 안내서](japan-appi-guide.md) | PPC 통칙편 189/189쪽 및 선정한 외국 이전·제3자 제공·가명정보·SME 자료 완독. APPI Q&A 본문 153개 답변과 분야별 지침은 미열람이며 범위 밖으로 표시 |
| 중국 PIPL | [중국 안내서](china-pipl-guide.md) | 선정한 CAC 공식 규정·문답·양식과 TC260 합규감사 실무지침 109쪽을 근거표에 따라 검토. 전체 중국 개인정보 관련 지침을 망라한 것은 아님 |
| EU GDPR | [EU 안내서](eu-gdpr-guide.md) | EDPB SME 안내 10개와 2026년 사업자용 설계·기본설정 PDF 4/4쪽 확인. GDPR 전체와 연결된 모든 세부 지침을 읽은 것은 아님 |
| 영국 UK GDPR | [영국 안내서](uk-data-protection-guide.md) | ICO 2022 기본 PDF 199쪽 본문 전체를 공식 PDF 텍스트로 확인하고, 주제별 최신 안내를 추가 대조. PDF 바이너리는 403으로 로컬 보존하지 못함 |
| 미국 캘리포니아 CCPA/CPRA | [캘리포니아 안내서](california-ccpa-guide.md) | 2026 시행 규정 103/103쪽, 공식 안내 PDF 2종 각 2/2쪽 및 적용·현행성 안내 페이지 확인 |
| 싱가포르 PDPA | [싱가포르 안내서](singapore-pdpa-guide.md) | PDPC 공식 가이드 4종 164/164쪽 전체 확인·보존. 각 가이드가 링크한 별도 후속자료는 범위 밖으로 표시 |

원문이 PDF이고 내려받을 수 있으면 `sources/<관할>/`에 원본을 보존합니다. 페이지형 안내서는 공식 URL·페이지 제목·수정일·완독 점검표를 기록합니다. 각 문서는 최소한 다음 항목을 포함합니다.

- 출처 기관, 공식 원문 URL, 문서명, 발행·개정일, 확인일, 원문 페이지 수/웹페이지 수
- 실제로 확인한 페이지 또는 절의 범위와 전체 완료 여부
- 원문 목차 순서에 따른 한국어 요약, 해당 페이지/절 근거, 실무상 필요한 확인자료
- 법정 의무와 권고 실무의 구분, 적용 예외·대상, 시행 중/예정/제안 상태
- 국제요정 질문은행에 반영할 수 있는 내용과 별도 현행성 확인이 필요한 쟁점

원문 전체를 직역해 재배포하는 대신, 원문 구조를 따라 충분한 범위를 빠짐없이 요약하고 필요한 짧은 용어만 인용합니다. 원문은 각 공식 링크 또는 `sources/` 파일에서 확인합니다.

공개 페이지의 **기업 상담소 → 국가별 안내서 읽기** 메뉴에서 이 여섯 한국어 학습본을 관할별로 열람할 수 있습니다. 자가점검 결과의 근거 펼치기에도 연결된 안내서 본문을 함께 표시합니다. 각 질문과 안내서 절의 대응은 [`ko/question-guide-references/`](ko/question-guide-references/)에 기록하며, 전수 정합성 검사는 `node scripts/validate-business-guide-mappings.mjs`로 실행합니다. 앱 제공용 콘텐츠는 `npm run build:business-guides`로 생성합니다.
