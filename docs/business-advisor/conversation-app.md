# 기업 개인정보 상담 앱: 대화·자료 연결 설계

## 제품 동작

앱의 기본 작업은 검색이 아니라 대화입니다. 사용자는 국가 필터나 검색식부터 고르지 않고, 상황을 자연어로 설명합니다. 앱은 대화 맥락에서 관련 관할과 주제를 찾고 자료를 내부적으로 조회한 다음, ChatGPT가 질문에 맞는 한국어 답변을 작성합니다. 필요한 정보가 부족하면 답변 가능한 부분을 먼저 말하고 필요한 후속 질문을 합니다.

검색은 답변에 쓸 근거를 모으는 서버 내부 단계입니다. 검색 결과 목록을 사용자가 훑어보는 별도 제품은 만들지 않습니다. 답변 밑의 출처 표시는 답변을 확인하는 용도입니다.

## 자료 범위

매 질문에서 다음 전체 자료 집합을 검색 대상으로 삼습니다.

1. `data/business-readiness/questions/`의 일본·중국·EU·영국·캘리포니아·싱가포르 질문은행.
2. `docs/business-advisor/guides/`의 6개 관할별 기업 안내서 한국어 학습본.
3. `docs/business-advisor/references/`에 저장한 사용자 제공 PDF 3종의 페이지별 Markdown 변환본: 중국 규제대응 가이드, EU GDPR 안내서, 해외 개인정보보호 법률 상담사례집.
4. `docs/jurisdiction-specific-self-assessments-2026-11.md`의 질문 설계와 누락 점검 내용.
5. `loadPublicSearchCorpus()`가 제공하는 현재 공개 자료: 공개 동향, 발행된 법제 번역, 발행된 법제 비교 셀.

비공개 작업실 원고, 미발행 자료, 관리자 데이터는 읽지 않습니다. 공개 Supabase 자료를 불러올 수 없는 경우에도 저장소의 질문은행·안내서·제공 PDF 변환본으로 대화를 이어갑니다. 공개 DB가 연결되지 않은 사실은 API 상태에 남아 추적할 수 있으며, 공개 자료가 모두 정상 연결된 것처럼 가장하지 않습니다.

## 답변 흐름

```text
자연어 질문 + 현재 대화(메모리만)
  -> 서버가 전체 공개/정적 자료에서 관련 문단을 찾아 ChatGPT 앱으로 전달
  -> 사용자의 ChatGPT 연결이 Responses API에 자연어 답변을 요청
  -> 매 답변에서 web_search로 최신 웹 정보를 확인하고 내부 자료와 종합
  -> 답변 + 국제요정 자료 인용 + 웹 인용 표시
```

- 웹 검색은 모든 답변의 필수 기본 단계입니다. 계정/모델이 이를 지원하지 않으면 이유를 안내하고, 내부 자료만으로 임의 대체하지 않습니다.
- 자가점검 결과 화면의 “자가점검 결과를 토대로 AI 상담하기” 버튼은 선택 지역별 응답 요약과 보완 항목을 gzip 압축한 `globaltrend-advisor://` 딥링크로 설치된 데스크톱 앱에 전달합니다. 앱은 실행 중 메모리에만 결과를 두고 상담을 시작하며, 웹 사이트 DB에는 저장하지 않습니다. 준비 완료 답변과 ‘해당 없음’의 자유 입력 사유는 전달하지 않습니다.
- Windows 앱은 첫 실행 때 딥링크 주소를 앱에 연결합니다. 앱이 설치되지 않았거나 연결되지 않은 경우 자가점검 결과 화면의 다운로드 링크를 사용합니다.
- 딥링크를 받아 실행한 상담은 사용자가 버튼을 누른 의사에 따라 ChatGPT 연결에 전달됩니다. 앱은 전달된 자가점검 답변을 사용자의 응답으로 취급하며 준수 여부의 판정으로 단정하지 않습니다.
- 내부 자료 일부만 질문과 맞아도 그 부분에서 확인되는 범위는 먼저 답합니다. 자료가 완전하지 않다는 이유로 무조건 중단하지 않고, 미확인 부분을 분리합니다.
- 법정 의무, 권고, 제안·시행 예정 규칙, 과거 사례는 서로 구별합니다. 관할별 제도를 하나의 법률 체계처럼 합치지 않습니다.
- 답변은 일반 정보이며 법률 자문·준수 판정·인증이 아닙니다.
- 답변은 인용표시 `[자료 1]`와 출처 카드를 연결합니다. 웹 인용은 Responses API가 반환한 URL 인용에서 구성합니다.

## 대화와 계정 정보

- 앱은 시스템 브라우저에서 사용자의 ChatGPT 계정을 직접 연결합니다. 사용자가 매 질문마다 국가를 고를 필요는 없습니다.
- ChatGPT 대화 이력은 앱 프로세스의 메모리에만 유지됩니다. 서버에 저장하지 않으며, 새 대화·앱 종료 시 사라집니다.
- API 요청은 `store: false`로 보내고, OAuth 토큰은 OS 보안 저장소에 보호합니다.
- 질문·대화 맥락·검색된 발췌는 답변 생성을 위해 사용자의 연결 계정으로 전송됩니다. 사용자에게는 전송 범위를 연결 화면과 개인정보 안내에 알립니다.
- 모델 목록은 로그인 계정의 `/v1/models` 응답을 바탕으로 보여줍니다. 모델과 웹 검색 지원은 계정, 요금제, 조직 설정에 따라 다를 수 있습니다.

## 정확성과 유지보수

- 정적 자료가 빠지면 서버 API가 에러로 반환합니다. 일부 안내서만 조용히 건너뛰고 완전한 자료 범위라고 표시하지 않습니다.
- DB에서 공개 동향과 법제 자료를 읽을 수 있는지 상태를 응답 메타데이터에 남깁니다. 동적 자료가 불가하면 저장소 자료로 대화는 가능하지만, 그 한계를 UI 또는 오류 상태에서 알려야 합니다.
- 질문별 원문·안내서 링크는 자가점검 결과에 따로 보이고, 대화 답변은 관련 발췌와 연결된 원문을 출처 카드로 제시합니다.
- 원문 접근 실패가 있어도 내부에서 확인 가능한 사실은 제공하고 접근할 수 없는 세부사항만 미확인으로 표시합니다.
- 실제 ChatGPT 사용자 계정으로 로그인, 모델 조회, 대화, 웹 검색 성공, 연결 해제까지 완료하기 전에는 실계정 검증 완료라고 보고하지 않습니다.
