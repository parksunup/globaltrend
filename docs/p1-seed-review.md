# P1 초기 기준 데이터 검토 가이드

이 PR은 수집기와 법제 비교 화면이 사용할 **초기 카탈로그**를 등록합니다.

## 등록되는 수집 출처

| 기관 | 용도 | 자동 수집 상태 |
|---|---|---|
| EDPB | 뉴스·보도자료 | HTML 수집기 연결 대기 |
| OECD | 개인정보·데이터 보호 주제 자료 | HTML 수집기 연결 대기 |
| CJEU/CURIA | 보도자료·판결 안내 | HTML 수집기 연결 대기 |

현재는 각 공식 시작 URL과 기본 파서 설정만 등록합니다. 실제 수집 전에는 robots.txt, 이용약관, 페이지 구조를 팀원이 확인해야 합니다.

## 등록되는 법제 카탈로그

한국 PIPA, 일본 APPI, 중국 PIPL, EU GDPR, UK GDPR, 미국 캘리포니아 CCPA, 싱가포르 PDPA를 등록합니다. 법령 원문·번역·조문 노드는 별도 작업에서 출처 확인 후 입력합니다. 따라서 이번 PR에서는 모두 비공개 상태입니다.

## 비교 기준

한국·일본 비교표를 기준으로 17개 행을 등록합니다.

1. 개인정보 범위
2. 법 적용 대상
3. 개인정보보호 원칙
4. 정보주체 권리
5. 처리근거 — 수집
6. 처리근거 — 이용
7. 제공
8. 특별한 보호가 필요한 정보
9. 가명·익명정보
10. 아동 개인정보
11. 안전성 확보조치
12. 처리 위탁
13. 국외이전
14. 과징금
15. 시정조치 등
16. 유출 등의 통지·신고
17. 데이터활용 촉진

기준표도 법제 검수 전까지 비공개입니다. 17개 기준의 명칭과 순서는 팀원이 작업 브랜치에 추가한 한국·일본 비교표 원본과 대조합니다.

## 검수 체크리스트

- [ ] 세 기관의 시작 URL과 수집 허용 범위를 확인했는가
- [ ] 각 법제의 공식 원문 URL이 현재 유효한가
- [ ] 17개 기준의 명칭과 순서가 한국·일본 비교표와 일치하는가
- [ ] 팀원 계정 생성 후 team_memberships를 안전하게 등록했는가
