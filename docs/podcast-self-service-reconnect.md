# NotebookLM 사이트 재연결

## 사용 방법

최초 한 번은 팟캐스트 전용 Chrome 프로필에 연결 도구 0.2.0을 설치합니다. 이 프로필에는 psunup@gmail.com 계정만 로그인합니다. 다른 Google 계정을 함께 쓰지 않습니다. 다른 계정이 표시되거나 전용 계정을 확인하지 못하면 전달하지 않습니다.

1. 국제요정 사이트 관리자 계정으로 팟캐스트 제작 화면에 로그인합니다.
2. **Google 로그인 열기**를 누릅니다.
3. 새 NotebookLM 탭에서 전용 Google 계정으로 직접 로그인합니다. 비밀번호나 인증 코드를 사이트·채팅에 입력하지 않습니다.
4. NotebookLM 오른쪽 위 Google 계정 메뉴에서 이메일을 확인합니다.
5. 국제요정 화면으로 돌아와 **로그인 마쳤습니다 · 연결하기**를 누릅니다.
6. **클라우드 인증 확인 완료**가 표시될 때까지 기다립니다. 클라우드 실행은 약 10분 간격이며 GitHub 상황에 따라 늦어질 수 있습니다.

로그인 정보 전송에 성공한 캡처 탭은 도구가 닫습니다. 같은 로그인 상태를 로컬과 클라우드에서 동시에 사용하지 않도록, 연결 후 이 전용 프로필로 NotebookLM 작업을 계속하지 않습니다. 재연결 후에도 Google이 로그인을 다시 요구할 가능성은 있습니다.

재연결은 새 회차 생성이나 자동 공개 선택 변경이 아닙니다. 기존 요청이 있으면 해당 요청의 설정대로 이어집니다. 기존 요청에서 자동 공개를 선택했다면 완성 후 공개될 수 있습니다. 새 요청을 중복으로 만들지 않습니다.

## 처리 경로

페어링한 제작 화면 → 확장 도구의 전용 NotebookLM 탭 → 선택한 Google 쿠키만 관리자 API로 전달 → Supabase Vault 암호화 임시 보관 → 기존 OIDC 클라우드 실행기에서 실제 접속 검증 → GitHub 전용 키로 기존 세션 암호화 저장.

- API는 관리자 로그인·동일 출처·크기·전용 계정·쿠키 범위를 확인합니다. 비밀번호는 받지 않습니다.
- 계정 확인에 쓰는 Google 메뉴의 이메일 외에 NotebookLM 문서 본문을 가져오지 않습니다.
- 쿠키 값은 window.postMessage나 Chrome storage에 저장하지 않습니다. 페어링한 탭의 isolated world에서 같은 사이트 API로만 보냅니다.
- 임시 로그인은 Vault에 암호화되어 보관되며 사이트·일반 팀원·일반 DB API에 반환하지 않습니다. 15분 내 사용하지 않으면 다음 획득 시 제거하고 실패로 표시합니다.
- 기존 단일 세션 lease와 버전 확인을 사용합니다. 진행 중인 lease나 최근 2분 내 요청이 있으면 덮어쓰지 않습니다.
- 복구용 첫 실행은 인증만 검증합니다. 성공한 경우에만 기존 세션 버전을 증가시켜 저장하고 Vault의 일회용 사본을 삭제합니다. 명시적인 인증 거절 때도 일회용 사본을 지웁니다.
- 제작·공개 스위치와 기존 회차의 자동 공개 선택은 재연결 함수가 바꾸지 않습니다.
- Chrome의 Google 쿠키 접근 권한은 계정별로 제한되지 않으므로 전용 프로필 분리가 필수입니다. 이메일 표시는 보조 확인이며 Google이 제공하는 계정별 쿠키 격리는 아닙니다.

## 배포 순서

1. DB 마이그레이션을 적용합니다. `private.podcast_reconnect_state.available`은 기본 false입니다.
2. 수정된 worker와 사이트 코드를 main에 병합·배포합니다. 이전 worker는 새 복구 payload를 이해하지 못하므로 순서를 바꾸지 않습니다.
3. 검사 후 `available=true`로 전환합니다. 이 스위치는 제작·공개를 켜지 않습니다.
4. 전용 Chrome 프로필의 확장 도구를 0.2.0으로 업데이트하고 권한을 확인합니다.
5. 실제 사이트에서 재연결 → 인증 검증 → 임시 사본 제거 → 다음 회차 연결을 확인합니다.

자동 검사: Node 재연결·확장 경계 검사, Python 암호화 갱신 검사, DB 관리자 권한·암호화 보관·일회용 제거·버전 보존 검사. 로컬 검사만으로 Chrome 권한 승인과 실제 Google 로그인을 검증했다고 보고하지 않습니다.
