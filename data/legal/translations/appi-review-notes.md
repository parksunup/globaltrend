# APPI 판본·번역·누락 대조 검토 메모

조사일: 2026-10-06. **부분 번역 초안·전문 미완성·사람 검수 미착수**.

## 원문·판본·범위

[e-Gov 원문](https://laws.e-gov.go.jp/document?lawid=415AC0000000057)과 [선택 판본 API](https://laws.e-gov.go.jp/api/2/law_data/415AC0000000057_20261001_507AC0000000070)를 확보했다. 고정 판본 URL도 별도로 요청하여 동일 판본 반환을 확인했다.

- 법률명: 個人情報の保護に関する法律, 平成十五年法律第五十七号. 관할권: 일본.
- 판본: `415AC0000000057_20261001_507AC0000000070`. API 상태: `CurrentEnforced`.
- 선택 개정법: 日本学術会議法, 令和七年法律第七十号. 개정법 공포일 2025-06-18, 선택 개정 판본 시행일 2026-10-01. APPI 최초 공포일 2003-05-30. 법 전체의 최초 시행일과 구분한다.
- 본칙 185개 조문, 부칙 22개 묶음, 별표 2개를 확보했다. 개정법 부칙 21개 묶음에는 원문 자체에 `Extract=true`가 있다. 통합 원문에 실린 부칙 발췌도 번역 범위에 포함하되 각 개정법 전체 부칙을 확보했다고 표시하지 않는다.
- 이전의 접근 차단·판본 미확정·0개 번역 기록은 이번 결과로 갱신했다. PPC 일부 신구대조표로 법문을 합성하지 않았다.
- API 응답 및 정규화 법문 SHA-256은 [appi.json](./appi.json)의 `source`에 있다. 정규화 방식: UTF-8 JSON, `ensure_ascii=False`, `sort_keys=True`, `separators=(',', ':')`. 원문 다운로드 전체는 Git에 넣지 않았다.

## 이용·재배포 조건과 공개 상태

[일본 저작권법 공식 API](https://laws.e-gov.go.jp/api/2/law_data/345AC0000000048)의 **본칙 제13조 제1호**는 `憲法その他の法令`(헌법 및 그 밖의 법령)을 해당 장의 권리 대상이 될 수 없는 저작물로 열거한다. 제4호는 공공기관이 작성한 해당 법령 등의 번역물·편집물도 열거한다. 이번 초안은 법령 자체를 프로젝트가 새로 번역했으며 제3자가 작성한 번역물을 전재하지 않았다.

이 확인을 근거로 **법령 자체에 대한 자체 번역 초안을 검토용 PR에 포함**한다. 사이트 디자인·로고·해설·제3자 번역까지 재사용할 수 있다는 뜻은 아니다. e-Gov `/terms/` 요청은 HTML 앱 셸만 반환하여 이용규약 본문을 확인하지 못했다. e-Gov에 PPC 조건이 자동 적용된다고 판단하지 않는다. 출처·판본·번역 주체·가공 사실·비공식 초안 상태를 번역 문서에 기재했다.

[PPC 이용규약](https://www.ppc.go.jp/notice/kiyaku)이 안내하는 [PDL1.0](https://www.digital.go.jp/resources/open_data/public_data_license_v1.0) 본문도 열람했다. 적용 대상 콘텐츠의 복제·공중송신·번역·변형 및 상업 이용을 허용하며 출처와 가공 사실·주체 표시를 요구한다. 제3자 권리·별도 규칙·로고 등 예외가 있다. 이는 PPC 자료를 추가 사용하는 경우의 조건으로, 이번 e-Gov 법령 자체의 권리 근거와 구분한다.

사람 검수와 제품 공개 승인은 미완료다. 검토용 저장소 초안을 공식 번역이나 검수 완료 콘텐츠로 사용하지 않는다.

**58/185 = 31.35%는 본칙 조문 수 기준**이다. 부칙·별표를 포함한 법 전체의 진행률로 사용하지 않는다. 원문 목차(TOC)의 반복 제목은 본문 개수에 중복 산입하지 않았다. 조문별 번역 분량도 동일하지 않다.

원문 구조 1,317개 노드와 미번역 식별자는 [appi.json](./appi.json), 조문별 상태는 [appi-status.md](./appi-status.md)에 기록했다. 제1조~제58조의 모든 조·항·호·목을 연결하고 해당 구간의 구조·순서만 대조했다. 나머지 전체 순서 대조와 문장별 의미·조건·예외의 사람 검수는 미실행이다. 노드 수가 같다는 것만으로 번역 정확성이나 문장 누락 부재를 확정하지 않는다.

## 이어서 할 작업

제59조부터 같은 appi.md에 이어 쓰고 본칙 이후 제공된 부칙·별표를 원문 순서로 번역한다. 마지막에 원문 목차·본문·부칙·별표를 모두 대조한다. APPI 전문 미완성이므로 일본 비교 셀도 미검토로 유지한다. 다른 해외법에도 공식 판본 확보 → 전체 번역 → 누락 대조 → 기존 17개 기준 연결 순서를 적용한다. 사용자가 원문을 모두 찾아 첨부하는 것은 선행 조건이 아니다.

## 이어 쓴 구간: 제41조~제58조

가명가공정보·익명가공정보의 작성·제공·재식별 금지, 인정개인정보보호단체, 적용 제외·특례까지 같은 문서에 이어 작성했다. 추가 번역은 원문 일본어를 직접 읽어 작성했으며 자동 번역 모델의 출력이 아니다. 제48조 제1항 제3호의 イ·ロ는 가(イ)목·나(ロ)목으로 나누어 앵커를 유지했다. 제47조의 참조도 제48조 제3호 나목으로 대응했다. 제41조·제42조의 준용·바꾸어 읽는 문구, 제57조의 적용 제외와 제58조의 공공부문 특례는 별도 법률전문 검수 대상이다. `拘禁刑`은 구금형으로 잠정 번역했다.

현재 작성 범위: 본칙 58개 조, 153개 항, 98개 호, 2개 목, 4개 장 제목, 10개 절 제목. 번역 앵커 325개를 JSON·Markdown과 대조했다. 제59조 이후, 부칙 및 별표는 미번역이다. 본칙 조문 수 기준 진행률 31.35%를 전체 법률 진행률로 사용하지 않는다.
