# 일본 APPI 판본·번역·공개 보류 검토 메모

조사일: 2026-10-06 (Asia/Seoul) · 대상: 個人情報の保護に関する法律 · 관할권: 일본

## 확인한 사실

1. [PPC 법령 안내](https://www.ppc.go.jp/personalinfo/legal/)를 HTTP 200으로 열람했습니다. 법률명은 `個人情報の保護に関する法律`이고 안내에는 `平成15年5月30日法律第57号`가 표시됩니다. 이는 법률번호·공포일 안내이며 법 전체의 단일 시행일 확인을 대신하지 않습니다.
2. 동일 안내에서 `令和８年10月１日施行版 新旧対照表` 링크를 확인했습니다. 날짜를 2026-10-01로 환산하되 **선택할 공식 통합 판본 자체를 확정한 것은 아닙니다**.
3. [개정 대조표 PDF](https://www.ppc.go.jp/files/pdf/261001_houritsu_shinkyu.pdf)는 HTTP 200으로 확보했습니다. 표제에 `(抄)`가 있고 별표 첫째 등의 일부 개정 대조만 담겨 있습니다. 전문이나 전체 부칙이 아닙니다. 이 파일로 전체 현행법을 합성하거나 조문 수를 계산하지 않았습니다.
4. 안내의 [개정 경위 PDF](https://www.ppc.go.jp/files/pdf/230401_personal_development.pdf)도 HTTP 200으로 확인했습니다. 문서 제목은 `個人情報保護法の成立及び改正に関する主な経緯`이며 법문이 아닙니다. 파일명의 날짜만으로 2023년 통합 법문이라고 판단하지 않았습니다.
5. 기존 e-Gov 주소는 HTTP 301로 `laws.e-gov.go.jp`의 같은 법령 식별자 주소로 이동합니다. 새 도메인의 본문은 HTTPS 프록시 연결 단계에서 403으로 차단됐습니다. 법령 본문이 없다는 뜻이나 대상 사이트 자체의 거부라고 단정하지 않습니다.

개정 대조표 PDF의 SHA-256: `d7b8a93f4c5b851816f26f893d46c4bd768dde32b03e8d6894061e01c5239e19`. 다운로드 자료는 조사용 임시 경로에만 두고 공개 저장소에 추가하지 않았습니다. 이것은 해당 대조표의 해시이며 전체 법문의 해시가 아닙니다.

## 이용·재배포 조건

[PPC 이용규약](https://www.ppc.go.jp/notice/kiyaku)과 [사이트 안내](https://www.ppc.go.jp/notice)는 HTTP 200으로 열람했습니다. 이용규약은 다음을 안내합니다.

- 특기 및 권리표시가 없는 콘텐츠에 대해 공공데이터 이용규약 제1.0판(PDL1.0)에 따른 이용조건을 적용한다고 안내합니다.
- 이용 시 출처를 기재해야 합니다.
- 편집·가공해서 이용하면 출처와 별도로 편집·가공 사실을 표시해야 합니다.
- 가공된 정보를 일본 정부나 기관이 작성한 것처럼 공개해서는 안 됩니다.

연결된 [PDL1.0](https://www.digital.go.jp/resources/open_data/public_data_license_v1.0) 본문은 도메인 제한으로 열람하지 못했습니다. 출처·가공 표시 의무를 확인했다고 해서 전문 번역·재배포의 모든 조건과 제3자 권리 예외까지 확인한 것은 아닙니다. 외부 e-Gov 법문에 PPC 사이트의 조건이 자동 적용된다고 가정하지 않습니다.

따라서 **번역 본문 작성·공개를 보류**합니다. 판본을 확보한 뒤 해당 원문 공급자의 조건, 법령 본문과 부가자료의 권리 구분, 번역·공개·재배포 범위를 확인해야 합니다. 현재 파일에는 법령·기존 번역 전문을 넣지 않았으며 Git commit·push·PR 발행을 하지 않았습니다.

## 번역 결정·용어 메모

아직 원문 전문을 확보하지 않아 용어 번역과 조문 해석을 결정하지 않았습니다. 법령 표제의 한국어 작업명만 `개인정보 보호에 관한 법률`로 두었습니다. 기존 한국어 번역이나 영문 번역을 대신 입력으로 삼지 않았습니다.

판본 확정 후 용어별로 `원문 표현 / 잠정 번역 / 등장 조문 / 선택 이유 / 불확실성 / 사람 검수 상태`를 기록합니다. 개념이 유사하다는 이유로 한국법의 법적 의미를 덧붙이지 않고, 원문에 없는 해설은 본문에 삽입하지 않습니다.
