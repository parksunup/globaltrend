# GDPR 공개 요청에 따른 이용 조건 확인

사용자가 이용 조건을 확인한 후 공개하도록 요청했습니다. **공개는 아직 실행하지 않았습니다.** 공개가 금지되었다고 확인한 것이 아니라, 법령 본문과 자체 한국어 번역 전문에 적용되는 허용 조건을 확인하지 못했습니다. 기존 공개 보류 조건을 유지합니다.

## 공식 고지에서 확인한 범위

| 공식 출처 | 조회 결과 | 확인 범위와 한계 |
| --- | --- | --- |
| [EU 출판국 저작권 고지](https://op.europa.eu/en/web/about-us/legal-notices/publications-office-of-the-european-union-copyright) | HTTP 200, 본문 확보 | EU 소유 웹사이트 편집 콘텐츠는 CC BY 4.0이며 출처·변경 표시를 요구합니다. 개별 출판물과 EUR-Lex는 각 고지를 확인하도록 안내합니다. 이 내용을 GDPR 법문·번역 전문의 허가로 확대하지 않습니다. |
| [EU 출판국 배포 조건](https://op.europa.eu/en/web/about-us/legal-notices/general-conditions-of-dissemination) | HTTP 200, 본문 확보 | 온라인 무료 제공과 재사용 원칙의 한도에서 복제를 안내합니다. 무료 열람 자체를 번역 전문 재배포의 허가로 보지 않습니다. |
| [EUR-Lex 법적 고지](https://eur-lex.europa.eu/content/legal-notice/legal-notice.html) | HTTP 202, 빈 본문 | 다른 언어·인쇄용 요청에서도 고지 본문을 읽지 못했습니다. 재사용 허가 또는 금지로 판정하지 않습니다. |
| [EUR-Lex 재사용 상세](https://eur-lex.europa.eu/content/help/data-reuse/reuse-contents-eurlex-details.html) | 기존 조회 HTTP 202, 빈 본문 | 허용 대상·번역·표시 조건 미확정입니다. |
| [EU 이사회 저작권 고지](https://www.consilium.europa.eu/en/about-site/copyright/) | 프록시 연결 HTTP 403 | 본문을 읽지 못했습니다. |
| [유럽의회 법적 고지](https://www.europarl.europa.eu/legal-notice/en/) | 기존 조회 프록시 연결 HTTP 403 | 본문을 읽지 못했습니다. |

Council Decision (EU) 2017/1870의 적용 범위와 번역 조건도 공식 본문을 확보하지 못했습니다. 웹페이지가 HTTP 200이어도 오류 페이지·검색 화면이면 허가 증거로 사용하지 않았습니다. TLS 검증을 끈 브라우저 응답 역시 허가 증거에서 제외했으며 해당 설정을 복구했습니다.

[조회·범위 기록 JSON](./sources/gdpr-publication-check.json)에 URL·응답 상태·확보된 응답의 해시를 남겼습니다. 제3자 한국어 번역의 이용 허락은 별도이며, 첨부 번역 PDF를 그대로 재배포하지 않습니다.

## 공개 전 준비와 검수 범위

저장소 밖 `/workspace/legal-publication-candidate/`에 로컬 준비본을 만들었습니다. 영어 본문 필드는 제외하고 자체 한국어 초안·번호·구조·원문 해시를 유지했습니다. 이 경로는 공개 주소나 영구 보관을 보장하는 경로가 아닙니다.

기존 앱의 데이터 로더를 수정 없이 실행해 본칙 99개 조, 전체 구조 1,123개 항목과 한국어 본문 997개 항목을 읽는지 확인했습니다. 제목·장·절 등은 본문 항목 수와 별개입니다. 준비본의 공개 상태는 `withheld`, 사람 검수 상태는 `not_started`입니다. 이 검사는 Preview 화면을 방문한 검사도, 법률·번역 의미 검수도 아닙니다.

번역은 선택한 2016년 영어 관보 원판에 2018년 영어 정오표를 반영한 전체 초안입니다. 고려사항 173개·본칙 99개 조를 포함하지만 2026년 현행성 전체는 미확정입니다. EU 비교표는 기존 17개 기준의 별개 초안입니다. **사람이 실제로 검수했다고 확인된 번역 항목은 0개, EU 비교 셀은 0개**입니다. 공개 보류를 해제하더라도 이 상태를 검수 완료로 바꾸지 않습니다.

## 남은 확인과 환경 조치

법령 본문·자체 번역의 재사용 조건을 공식 고지에서 읽고, 확인된 조건에 맞는 출처·비공식 번역·변경 표시를 갖춘 뒤 공개 번역 두 파일과 EU 비교 셀을 함께 연결해야 합니다. 비교표와 번역의 검수 범위는 각각 기록합니다.

환경의 기존 네트워크 허용 목록은 읽을 수 없어 교체하지 않았습니다. 공식 고지의 대체 확인 경로에 필요한 추가 도메인은 `www.consilium.europa.eu`, `www.europarl.europa.eu`, `publications.europa.eu`입니다. 기존 목록을 유지한 채 추가해야 합니다. EUR-Lex의 HTTP 202 빈 응답은 사이트의 WAF 응답이어서 도메인 추가만으로 해결된다고 보장할 수 없습니다.

앱·Supabase·인증·환경변수를 수정하지 않았고 PR 병합도 하지 않았습니다.

## 이번 검사 결과

공식 관보·통합본문·정오표를 입력한 `validate-gdpr.py` 통과(1123개 항목·99조·173개 고려사항). 로컬 공개 준비본의 기존 로더 검사 통과(99조·본문997항목). `validate:data` 통과, 기존 테스트 22/22 통과·실패0·건너뜀0, `git diff --check` 통과. 검사는 권리 허가나 사람 의미 검수를 대신하지 않습니다.

## 환경 재시작 후 재확인

2026-10-13 새 실행환경에서 공식 고지를 다시 조회했습니다. OP 저작권 고지 HTTP200, EUR-Lex 법적 고지/재사용 상세 HTTP202·0바이트, 이사회·의회 고지 프록시 연결403입니다. `sources/gdpr-publication-check.json`의 `latest_retry_receipts`에 조회 시각·URL·응답 해시를 추가했습니다. 공개 허용 조건은 여전히 미확정으로 본문/비교 셀의 공개 보류를 유지합니다. 이후 [네 비교 기준의 선택 조건/예외 후속 대조](./gdpr-four-cell-review.md)를 진행했습니다.
