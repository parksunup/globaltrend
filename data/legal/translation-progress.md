# 법제별 번역·비교 진행표

상태 갱신: 2026-10-07 (한국 시각). **완성된 해외법 번역 전문 0개·비교 내용 작성 0/119셀.** 이 표는 완료 보고가 아니다. 길면 같은 법률 문서에 작업 단위별로 이어 쓰라는 요청에 따라 APPI 제1조~제108조 부분 초안을 저장했다.

자료를 직접 찾아 공식 판본과 범위를 확인한다. 사용자가 각국 원문을 찾아 첨부할 필요는 없다. 기존 17개 비교 기준은 architecture.md §6.0에 이미 기록되어 있으므로 그대로 유지한다.

## 이어 쓰는 순서

1. APPI 제109조부터 본칙 제185조까지 같은 appi.md에 작성한다. 원문에 실린 부칙 22개 묶음과 별표 2개를 이어 번역한다.
2. 원문 목차·본문·조·항·호·목·부칙·별표의 수와 순서를 대조하고 누락을 해결한다. 사람 검수 전에는 완성된 초안이어도 검수 완료로 표시하지 않는다.
3. 공식 한국어 PIPA 원문을 확보하여 한국 셀을, APPI 전문이 완성되면 일본 셀을 작성한다. 모든 셀에 관련 조항·핵심 요약·예외·번역 앵커·공식 URL·검수 상태를 넣는다.
4. 나머지 해외법도 판본 확정 → 전문 번역 → 누락 대조 → 해당 관할권 17셀 작성 순서로 진행한다. 공개 조건이 불확실한 번역 본문은 Git에 넣지 않고 메모에 이유를 적는다.

원문 접근·해시 증거는 [source-receipts.json](./source-receipts.json), 원문과 번역의 이용조건 및 영국 보완법은 [review-notes.md](./review-notes.md)에 있다. 접근 실패와 빈 응답을 원문 부재로 해석하지 않는다.

## 한국·일본 우선 작업과 남은 확인

사용자의 2026-10-07 (한국 시각) 지시에 따라 한국·일본 번역·비교부터 진행하고 다른 해외법의 추가 번역·비교는 뒤로 미룬다. [한국·일본 점검 문서](./japan-comparison-review.md)에 기존 17개 기준별 일본 초안 링크와 검토 질문을 기록했다. 비교 내용이 아직 작성되지 않았으므로 비교가 잘 되었다고 평가하지 않는다.

APPI는 제108조까지 이어 썼고 제109조 이후·부칙·별표가 남았다. 제106조의 법정 치환표 21행·63셀도 같은 문서에 초안으로 작성했다. 한국 공식 원문 재시도는 HTTP 503 또는 프록시 403으로 현행 판본 미확정이다. 한국 조 번호를 추정하지 않는다.

추가 네트워크 도메인 네 곳은 환경 설정에서 게시된 것으로 확인했다. EU·중국 대체 공식 출처 접근은 가능해졌고, 모델 파일은 제공 서버의 HTTP 403(Cloudflare 1010)으로 확보하지 못했다. 이를 설정 미적용으로 기록하지 않는다. 모델은 현재 초안 작성에 사용하지 않았다. 확보 원문과 이용조건의 세부 상태는 [검토 메모](./review-notes.md)에 보존한다.
