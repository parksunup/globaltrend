# 법제별 번역·비교 진행표

상태 갱신: 2026-10-07 (한국 시각). **선택 공식 원문 전체 번역 초안 1개(APPI)·사람 검수 완료 번역 0개·분류·요약 초안 34/119셀·사람 비교 검수 완료 0셀.** 모든 번역·분류는 사람 검수 전이다. 길면 같은 법률 문서에 작업 단위별로 이어 쓰라는 요청에 따라 APPI 본칙·제공 부칙·별표 전체 초안을 같은 문서에 저장했다.

자료를 직접 찾아 공식 판본과 범위를 확인한다. 사용자가 각국 원문을 찾아 첨부할 필요는 없다. 기존 17개 비교 기준은 architecture.md §6.0에 이미 기록되어 있으므로 그대로 유지한다.

## 이어 쓰는 순서

1. APPI의 선택 공식 통합 원문에 실린 본칙·부칙·별표 전체 초안을 작성하고 구조를 대조했다. 각 개정법의 발췌되지 않은 부칙까지 번역한 것은 아니다.
2. 원문 목차·본문·조·항·호·목·부칙·별표의 수와 순서를 대조하고 누락을 해결한다. 사람 검수 전에는 완성된 초안이어도 검수 완료로 표시하지 않는다.
3. 한국·일본 34개 셀의 관련 조항·자체 요약·주요 예외·읽기 링크·공식 URL·검수 상태를 작성했다. 기준별 근거의 법률적 완전성, 부칙 적용과 시행령·규칙·지침 조건을 사람이 검수한다.
4. 나머지 해외법도 판본 확정 → 전문 번역 → 누락 대조 → 해당 관할권 17셀 작성 순서로 진행한다. 공개 조건이 불확실한 번역 본문은 Git에 넣지 않고 메모에 이유를 적는다.

원문 접근·해시 증거는 [source-receipts.json](./source-receipts.json), 원문과 번역의 이용조건 및 영국 보완법은 [review-notes.md](./review-notes.md)에 있다. 접근 실패와 빈 응답을 원문 부재로 해석하지 않는다.

## 한국·일본 우선 작업과 남은 확인

사용자의 2026-10-07 (한국 시각) 지시에 따라 한국·일본 번역·비교부터 진행하고 다른 해외법의 추가 번역·비교는 뒤로 미룬다. [한국·일본 점검 문서](./japan-comparison-review.md)에 기존 17개 기준별 일본 초안 링크와 검토 질문을 기록했다. 한국·일본 분류·요약 초안을 작성했지만 번역·법률적 완전성·예외·시행 관계의 사람 검수 완료로 표시하지 않는다.

APPI 선택 공식 통합 원문의 1,317개 구조 노드와 부칙 항 표제·별표 관련 조문 표시까지 초안으로 작성했다. 수·순서 대조와 사람 의미 검수를 구분한다. 제106조의 법정 치환표 21행·63셀도 같은 문서에 초안으로 작성했다. 한국 공식 법령명·검색·본문의 공개 조회 경로에서 판본과 본문 HTML을 확보했다. 한국 비교 셀에는 선택 본칙과 2027년 시행 단서를 구분하고 유출·과징금 경과규정을 연결했다. 나머지 시행령·전체 개정별 적용 관계는 사람 검수가 필요하다.

추가 네트워크 도메인 네 곳은 환경 설정에서 게시된 것으로 확인했다. EU·중국 대체 공식 출처 접근은 가능해졌고, 모델 파일은 제공 서버의 HTTP 403(Cloudflare 1010)으로 확보하지 못했다. 이를 설정 미적용으로 기록하지 않는다. 모델은 현재 초안 작성에 사용하지 않았다. 확보 원문과 이용조건의 세부 상태는 [검토 메모](./review-notes.md)에 보존한다.
