# GDPR 사람 검수 전 작업 정리

2026-10-13. 사람 검수는 다른 법률과 함께 나중에 진행한다는 사용자 요청에 따른 인계 자료입니다. 번역과 비교표는 각각 별개 초안이며, 실제 사람 검수는 모두 미착수입니다. 이 문서는 전체 법률 검수 완료나 공개 승인을 뜻하지 않습니다.

## 준비된 결과물

| 결과물 | 준비 범위 | 현재 상태 |
| --- | --- | --- |
| GDPR 한국어 번역 | 선택 보정판 본칙99조·고려사항173개, 전체1123구조 항목 | 누락0, 사람 검수0/1123, 본문 공개 보류 |
| EU 조항별 비교 | 기존17기준의 요약·예외·공식URL·번역 연결243개 | 초안17/17, 사람 검수0/17, 본문 공개 보류 |
| 전체 비교표 | 기존17기준×7법제119셀 | 한국·일본34셀 및EU17셀 초안, 다른68셀 미검토 |
| 검수 대상 목록 | 번역1123항목+EU비교17셀=1140행 | 실제 검수자·검수일·결과는 빈 값 |
| 로컬 열람·보관 묶음 | HTML·Markdown·JSON·CSV·용어집·기존 법제 근거·파일 해시 | Git/Preview 밖에 생성, 공개 배포하지 않음 |

선택 판본은 `32016R0679-OJ20160504-EN-CORR20180523`입니다. 2016영어 관보 원판에 확인된2018-05-23 영어 정오표의17개 항목을 반영했습니다. 발효2016-05-24, 적용2018-05-25입니다. 본칙은 영어 통합본문 EN000.002와 대조했고, 고려사항은 관보 원판과 정오표를 합성했습니다. 통합본문을 법적 효력이 있는 관보 자체로 표시하지 않습니다.

공식 원문·정오표·통합본문 URL 및 원문과 초안의 항목 해시는 [검수 목록](./gdpr-human-review-queue.csv)과 [판본 기록](./sources/gdpr-edition-review.md)에 있습니다. [번역 검토 메모](./translations/gdpr-review-notes.md)와 [비교 검토 메모](./gdpr-comparison-review.md)는 별도로 유지합니다. APPI의 부칙21묶음이 원문 자체의 발췌라는 한계도 보존했습니다.

## 공개하지 않고 내용 읽기

현재 실행환경의 `/workspace/legal-review-gdpr-20261013.zip`에 보관용 묶음을 만들었습니다. 압축을 풀고 `index.html`을 브라우저로 열면 번역 전체와 EU17개 기준 비교 초안을 볼 수 있습니다. 검색·조문 이동·비교 셀에서 번역으로 이동하는 기능이 있습니다. 원문에 없는 해설은 번역 본문에 추가하지 않았습니다. 열람 파일의 상태 설명은 본문과 구별합니다.

전체17×7 비교표는 같은 폴더의 `criteria-mapping.md/csv`로 제공합니다. 한국·일본 근거 문서도 상대경로로 연결되도록 사본을 포함했습니다. 자체 한국어 번역 JSON에서는 영문 본문 필드만 제외하고 번호·구조·원문 해시·미검수 상태를 보존했습니다. 원본 작업 JSON은 변경하지 않았습니다. 원문의 영어 법률명·판본 식별 정보는 메타데이터에 유지합니다.

외부 프로그램·로그인·서버·자동 전송 없이 읽는 로컬 자료이며, 공식 출처 링크를 누를 때만 외부 사이트로 이동합니다. 피드백을 저장하거나 검수 상태를 자동 변경하는 기능은 없습니다. 이 경로는 GitHub/Preview 주소나 영구 보관 장소가 아니므로 보관하려면 묶음 파일을 내려받아야 합니다. 묶음에 포함된 manifest의 파일 해시로 사본 일치를 확인할 수 있습니다.

공개 Preview에는 GDPR 번역 전문과 EU 비교 본문을 넣지 않았습니다. Preview의 접근 제한을 확인하거나 설정한 것도 아닙니다. 로컬 열람 준비가 공개 허가 또는 비공개 Preview 배포를 뜻하지 않습니다.

## 끝낸 점검과 한계

- 공식 관보·통합본문·정오표 입력 구조 검사:1123항목·99조·173고려사항, ID·수·순서·원문 해시·앵커·17개 정정·누락0 확인.
- 명시적 조문 참조245항목의 조 번호 집합·조 단위 범위 불일치 후보0. 다른878항목은 명시적 참조 없음. 항·호·참조 횟수·외부법령 귀속·조건/예외의 의미까지 검증하는 검사가 아닙니다.
- 기업 규모 용어2항목 통일 및 용어집328항목/320영어 키 정리. 다른1121번역 항목 보존. 모든 용어의 의미 일치를 확정한 것은 아닙니다.
- 기존17비교 기준의 선택 근거·조건·예외 후속 모델 대조 기록과 실제 번역 연결243개를 유지. 모델의 선택 대조는 전체 의미 검수나 사람 검수가 아닙니다.
- 로컬 묶음의 파일 해시·압축 무결성·한국어 본문 일치·번역1123항목·비교17셀·243링크·검색/이동·자동 네트워크 요청 없음 점검.
- APPI/PIPA corpus, 팀 데이터 검사, 기존 테스트22개 통과. 검증은 이용 허락이나 사람 검수를 대신하지 않습니다.

관리형 브라우저는 `file://` 이동을 차단하여 실제 파일 열기 방식은 이 환경에서 확인하지 못했습니다. 대신 생성한 HTML을 브라우저 메모리에 넣어 렌더링·검색·이동·본문 일치를 점검했습니다. 차단 설정이나 TLS 검증을 해제하지 않았습니다.
