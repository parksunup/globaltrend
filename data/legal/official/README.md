# 한국 개인정보 보호법 공식 원문

`pipa-20260911.json`은 [국가법령정보센터의 2026년 9월 11일 시행 판본](https://law.go.kr/LSW/lsInfoR.do?chrClsCd=010202&efYd=20260911&lsiSeq=283839) HTML에서 본칙 조문과 부칙을 추출한 화면용 자료입니다. 법률 제21445호(2026년 3월 10일 일부개정)로 표시되는 판본입니다.

- 본칙 조문 표제 131개에는 삭제 조문 표제도 포함됩니다. 부칙은 13개 법률 묶음입니다.
- 원본 HTML의 SHA-256은 JSON의 `sourceSha256`에 기록했습니다.
- 다시 생성할 때는 공식 HTML을 내려받아 `node scripts/build-pipa-official.mjs <HTML 파일>`을 실행합니다. 판본과 조문 수를 확인한 뒤 변경을 검토해야 합니다.
- 2026년 9월 11일 이후 시행되는 개정규정, 최신 개정 여부와 원문 해석은 국가법령정보센터에서 다시 확인해야 합니다.
