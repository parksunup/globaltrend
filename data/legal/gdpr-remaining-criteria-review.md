# GDPR 남은13개 비교 기준 후속 대조와 현재 완료 상태

검토일: 2026-10-13(한국 시각). **GDPR 전체 작업은 아직 마무리되지 않았습니다.** 선택 판본의 번역 초안과17기준 비교 초안은 작성됐고 선택 조건/예외의 후속 모델 대조도17기준에 걸쳐 진행했지만, 공개 이용 조건 확인과 공개 반영이 남아 있습니다. 사람 검수와2026년 현행성 전체 확인은 별도 미완료 사항입니다.

## 판본과 출처

선택 판본은2016 영어 관보 원판+확인된2018-05-23 영어 정오표 보정판입니다. 본칙은 확보한 영어 통합본문 EN000.002와 대조했습니다. 통합문서 자체는 법적 효력이 없는 문서화 도구이며, 관보 원판과 정오표가 근거입니다. 최신 현행판 전체를 확정한 것이 아닙니다.

## 검사

공식 관보·통합본문·정오표를 입력한 GDPR 검사 통과(1123항목·99조·173고려사항·17개 정정). APPI/PIPA corpus와 공개 CSV/Markdown 대응 검사 통과. 선택231항목 원문해시, 누적290항목/후속범위밖833항목, 13셀 변경과106셀 보존, EU243개 실제 한국어 연결 검사 통과. 이번 문구 보완은8셀이며고려사항연결22개를추가했습니다. 번역전문두파일은이번작업전과바이트동일합니다. 공개표는13개EU셀의보류메모만변경했고본문/링크공개는없습니다. 팀데이터검사통과, 테스트22/22·실패0·건너뜀0, `git diff --check` 통과. 기존Node모듈유형경고가있었으나실패는없습니다. 자동검사통과를사람검수로표시하지않습니다.
