# GDPR 비교 초안의 조건·예외 후속 대조

검토일: 2026-10-13. 기존 17개 기준 중 EU 기준 **4·5·6·8**의 선택한 조건과 예외를 모델이 원문과 대조했습니다. 기존 한국·일본 셀이나 다른 법제의 기준을 바꾸지 않았습니다. 번역 전문과 비교표는 별개 결과물로 유지합니다.

## 대조한 판본

2016년 영어 관보 원판에 확인된 2018-05-23 영어 정오표를 반영한 선택 보정판입니다. 본칙 99조는 확보한 영어 통합본문 EN000.002와 대조했고 고려사항은 원판과 정오표의 범위입니다. 2026년 현행성 전체 검증이나 회원국법·판례·지침의 적용 판단을 완료한 것은 아닙니다.

본칙과 고려사항을 동일한 형식의 독립 의무로 바꾸지 않았습니다. 제9조의 모든 예외에 동일한 필요성 문구를 일괄 적용하지 않고 각 호의 문언을 따랐습니다. 특정 사례에 대한 법률 자문이나 회원국별 적용 결론을 추가하지 않았습니다.

## 공개 조건 재확인

환경 시작 후 다시 조회했습니다. OP 저작권 고지는 HTTP200으로 확보했으나 개별 출판물과 EUR-Lex 고지를 확인하도록 안내합니다. EUR-Lex 고지와 재사용 상세는 HTTP202·0바이트, 이사회·의회 고지는 프록시 연결403으로 여전히 읽지 못했습니다. [공개 조건 확인 기록](./gdpr-publication-check.md)에 새 조회 증거를 추가했습니다. 조건 미확정을 금지 확인이나 공개 허가로 바꾸지 않았습니다.

## 검사

공식 관보·통합본문·정오표를 입력한 GDPR 구조 검사 통과(1123항목·99조·173고려사항). APPI/PIPA corpus와 공개 표·Markdown 대응 검사 통과(공개34셀·보류17셀). 선택69항목의 원문해시 대조, 비공개 네 셀 변경/115셀 보존, EU221개 연결 검사 통과. 공개 표는 네 셀의 보류 메모만 변경했으며 다른115셀은 동일합니다. 팀 데이터 검사 통과, 기존 테스트22/22·실패0·건너뜀0, `git diff --check` 통과. 기존 Node 모듈유형 경고가 있었으나 검사 실패는 없습니다. 자동 검사 통과를 사람 의미 검수로 표시하지 않습니다.
