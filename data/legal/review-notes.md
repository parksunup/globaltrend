## APPI 이용조건과 번역 결정

[일본 저작권법 공식 API](https://laws.e-gov.go.jp/api/2/law_data/345AC0000000048)의 **본칙** 제13조 제1호는 헌법 및 그 밖의 법령을 해당 장의 권리 대상에서 제외한다. 부칙의 같은 조 번호와 구별하여 확인했다. 제4호는 공공기관 작성 번역·편집물도 열거하지만 이 프로젝트가 타인의 번역을 전재할 일반 허락으로 해석하지 않는다.

[PPC 이용규약](https://www.ppc.go.jp/notice/kiyaku)과 [PDL1.0](https://www.digital.go.jp/resources/open_data/public_data_license_v1.0)을 확인했다. 적용 대상 자료의 번역·변형·복제·공중송신·상업 이용을 허용하며 출처·가공 사실·가공 주체를 표시해야 한다. 제3자 권리·로고·개별 규칙 등의 예외가 있다. PPC 이용규약이 e-Gov 원문에 자동 적용되는 것으로 표시하지 않는다. e-Gov `/terms/`는 HTML 앱 셸만 반환하여 규약 본문은 미확인이다.

이번 APPI 자체 초안은 법령 자체의 권리 제외를 근거로 검토용 PR에 포함한다. 공식 번역·일본 정부 작성물로 표시하지 않으며 사람 검수 전 상태를 유지한다. 용어 결정, 조·항·호·목·부칙·별표의 수 및 누락·확인 방법은 [APPI 검토 메모](./translations/appi-review-notes.md)에 별도로 기록했다.

## 싱가포르 이용규약 확인 사항

- 제5조는 제13조의 예외를 제외한 이용·복제·재배포에 AGC의 사전 서면 허가를 요구한다. 제7조는 무단 목적의 수정·이용을 금지한다.
- 제8조는 SSO 통합 법문을 unofficial version이라고 명시하고 권위 있는 법문을 대신한다고 보지 않도록 한다.
- 제13조는 법률의 이용·복제에 조건부 허락을 제공한다. 싱가포르 정부 저작권 및 AGC 허락에 의한 이용 사실, 최신판은 SSO에서 확인할 수 있다는 안내, 제작자의 정확성 책임이 조건이다. AGC/SSO의 제휴·지지 인상을 주면 안 된다.
- 제13조(d)는 **자동취득을 싱가포르 시각 03:00~07:00로 제한**한다. 이후 추가 자동취득은 이 시간을 준수한다. 최초 페이지 취득 시점의 조건 준수 여부는 별도 확인 필요하며, 추가 법문 자동취득은 중단했다. 과도한 요청·보안 우회는 허용되지 않는다.
- 제13조의 use/reproduce 문구만으로 자체 번역·수정·공개 저장소 재배포까지 허용된다고 확정하지 않았다. 이 범위 및 위 표시조건을 확인하기 전 PDPA 번역 본문은 Git에 넣지 않는다. 제14조의 허락 철회·조건 변경 가능성도 확인했다.

## 제출 상태·다음 작업

[번역 진행표](./translation-progress.md)를 따른다. 현재 완성된 해외법 번역 전문은 0개이고, 비교표 119셀은 모두 미검토다. 이는 요청한 전체 작업의 완료가 아니라 APPI 부분 초안과 조사 상태를 검토하기 위한 제출이다. 부분 번역은 같은 문서에 계속 이어 쓰며, 각 법률 전문과 누락 대조가 끝난 뒤 기존 17개 기준의 해당 관할권 셀에 근거·요약·예외·조항 링크·공식 URL·검수 상태를 넣는다. 사용자가 원문을 모두 찾아 첨부하는 것은 선행 조건이 아니다.

## 이번 이어쓰기와 접근 조건 갱신

직전 작업은 APPI 제41조~제58조였다. 이번에는 제59조~제105조를 원문 일본어에서 직접 읽어 같은 appi.md에 추가했다. 현재 초안은 본칙 185개 조·417개 항·249개 호·16개 목이다. 제공 부칙·별표는 미번역이며 사람 검수 미착수다. [장별 실제 범위](./translations/appi-status.md)는 제목 번역 수와 장 전체 작성 수를 구분한다. 제4장은 제59조까지이며 제58조에서 끝난다는 이전 PR 표현을 수정한다.

설정 초안에 추가했던 네 도메인은 환경 설정에서 **게시된 상태**로 확인했다. 목적지별 응답을 재검증한 결과는 다음과 같으며, 접근 성공을 전문 확보나 이용허락으로 해석하지 않는다.

EU 출판국에서 받은 영어 관보 원판의 본문 식별자 `art_1`~`art_99`가 순서대로 99개인지 확인했다. 장 11개, 절 15개, 고려사항 `rct_1`~`rct_173`도 확인했다. 제99조의 발효 규칙·적용일과 관보 일자를 읽었다. HTML 변환 생성 시점은 법령 개정일로 사용하지 않는다. 이 자료는 **원판**이며 2026년 현행 통합 판본으로 확정하지 않았다. PDF와 HTML의 원문 파일 전체는 Git에 넣지 않았다.

[출판국 저작권 고지](https://op.europa.eu/en/web/about-us/legal-notices/publications-office-of-the-european-union-copyright)는 EU 소유 편집 콘텐츠에 Creative Commons Attribution 4.0을 안내하고 출처·변경 표시를 요구한다. 출판물 자체는 각각의 저작권 고지를, EUR-Lex 콘텐츠는 EUR-Lex의 별도 고지를 확인하라고 명시한다. 제3자 자료·로고·상표 등의 예외가 있다. 따라서 이 웹사이트 편집물에 대한 허락만으로 GDPR 법령 자체의 한국어 번역 재배포 조건을 확정하지 않는다. EU 번역 본문은 아직 미작성·공개 보류다.

PIPL 검색·상세 응답의 bbbs는 `ff8081817b6472a3017b656cc2040044`다. 공포·시행일은 이 공식 메타데이터에서 읽었으며, 이전의 잘못된 gov.cn 후보를 근거로 하지 않았다. 상세 응답의 `content`는 74개 조의 **목차 트리**로 조문 본문이 아니다. 공개 다운로드 링크는 NPC가 안내하는 별도 파일 제공 호스트로 연결된다. 해당 본문을 확보했다고 표시하지 않는다. 다운로드·미리보기 응답의 내부망 URL이나 임시 서명값은 저장소에 넣지 않는다.

로컬 번역 처리 라이브러리(CTranslate2 4.6.0, SentencePiece 0.2.1)는 저장소 밖 `/workspace/legal-translation-tools/venv`에 있다. 앱 의존성·lockfile·환경변수 파일은 변경하지 않았다. 라이브러리 설치는 번역 모델 확보나 전문 번역 완료를 뜻하지 않는다. 현재 APPI 초안은 이 자동 번역 모델의 출력이 아니다.

조항 JSON을 번역의 입력으로 유지하고 `python data/legal/tools/render-appi.py`로 같은 문서와 누락 목록을 출력한다. 출력 도구는 법문이나 번역을 생성하지 않으며 미번역 항목을 누락 목록에서 숨기지 않는다. 제106조 제2항의 치환표 21행·63셀을 번역하고 출력 지원을 추가했다. 빈 셀은 원문의 빈 값인지 해시로 구분하고 표 셀의 순서·테두리 속성을 원문과 대조한다. 미번역 셀을 조 완료로 숨기면 검사에서 거부한다.

## 한국·일본 우선 비교 검토

사용자의 2026-10-07 (한국 시각) 지시에 따라 다른 해외법의 추가 번역·비교는 뒤로 미룬다. 현재 한국·일본 비교도 아직 미작성이다. [한국·일본 점검 문서](./japan-comparison-review.md)에 기존 17개 기준별 APPI 작성 구간의 확인 링크, 번역 미완성으로 판단할 수 없는 항목, 사람 검수 질문을 기록했다. 과징금과 일본의 罰金·過料를 동일하게 취급하지 않으며, 아동 동의 연령도 한국 기준에서 추정하지 않는다.

직전 작업에서는 한국 국가법령정보센터의 법령 페이지·법률명 조회를 재시도했으나 HTTP 503, 연결 경로는 프록시 403이었다. 이번에는 아래 경로에서 판본·본문 HTML을 확보했으며, 전체 범위 대조 후 비교 근거를 연결한다. 제106조의 표를 포함하여 APPI 본칙·부칙·별표를 같은 문서에 이어 쓰고 전체 누락 대조 후 한국·일본의 실제 비교 셀을 작성·검토한다.

직전 작업의 PIPA 공식 URL 재시도는 HTTP 403이었다. 이번 공식 공개 경로에서는 본문 HTML을 확보했다. 원문 존재 여부와 환경의 접근 실패를 구분하며 한국 조문을 추정하지 않는다.


## 모델별 작업 분담과 이번 결과

사용자가 토큰 절약을 위해 모델별 역할을 요청했다. gpt-6.1-sol은 필요한 원문 구간과 용어만 읽어 APPI 제109~123조의 초안을 작성했다. gpt-6-luna는 원문 조·항·호 대응 및 제1~108조 기존 번역 보존을 읽기 전용으로 확인했다. 통합 담당은 문서·진행률·공식 원문 확보·자동 검사·PR 갱신을 수행한다. 전체 대화 이력을 다른 모델에 전달하지 않았으며 불필요한 재번역과 다른 해외법 추가 조사를 하지 않았다. 모델 검사도 사람 의미 검수를 대신하지 않는다.

국가법령정보센터의 법률명에 공백이 포함된 공식 경로에서 iframe의 판본 URL을 확인했다. 해당 공개 페이지가 사용하는 lsInfoR.do 본문 경로에서 법률 제21445호·2026-09-11 시행 본문 HTML도 확보했다. 이전 실패 기록은 과거 관측으로 남기며 더 이상 한국 원문 미확보를 현재 상태로 표시하지 않는다. 원문에는 조문 선택·시행예정 표시 등 화면 요소가 있어 HTML 레이블 개수를 법률 조문 수로 단정하지 않는다. 정규화 범위·부칙·시행표지·이용조건을 검토한 뒤 실제 비교 근거를 연결한다.

이번에는 같은 모델 분담으로 APPI 제124~185조를 이어 작성하여 본칙 초안을 마쳤다. 법률 전문에는 부칙·별표도 포함되므로 전체 완료와 구분한다. 한국 저작권법 제7조 개별 경로는 HTTP 403, 법령 페이지는 HTTP 502여서 원문 재배포 조건을 확정하지 못했다. PIPA 본문은 조사용 로컬 파일에 보관하며 Git에는 넣지 않는다.
